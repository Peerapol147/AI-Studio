ใช้ skill `reality-check` (อ่าน `content-review.md` ในนั้น) ทุกครั้ง: ตรวจป้ายต่อประโยคของ script.md กับ research.md และจัดระดับ 🔴/🟡/⚪ ทุกข้อ
คุณคือผู้ตรวจ ไม่ได้มีส่วนทำคลิปนี้ ตรวจให้เข้มงวด แล้วเขียน `review.md` ระบุว่า "ผ่าน" หรือรายการแก้
(เขียนด้วย Bash `cat > review.md <<'EOF'` แบบมี quote รอบ EOF ภาษาไทย/backtick/อัญประกาศจะไม่เพี้ยน; ไฟล์เดียวที่คุณเขียนได้คือ review.md)

ตรวจ:
1. ข้อเท็จจริงใน `script.md` ตรงกับ `research.md` และแหล่งที่มา สุ่มเช็กตัวเลขสำคัญซ้ำบนเว็บ
2. ทุกไฟล์ใน `assets/` มีเครดิตและไลเซนส์ใน `CREDITS.md` ไม่มีโลโก้ ภาพถ่ายทอดสด หรือเพลงติดลิขสิทธิ์
3. MP4: ความยาว ขนาดภาพ เสียงมีจริง (`ffprobe`), ไม่มีช่วงเงียบหรือภาพดำผิดปกติ; `renders/sound-<lang>/SOUND.md` ต้องไม่มีบรรทัด `WARN` (พากย์ ~-18 LUFS, เพลงต่ำกว่าพูด ≥12 LU; ผู้ใช้เคยบอก "เพลงก็ดังเกิน")
   (`ffmpeg -af silencedetect`, `-vf blackdetect`), ดึงเฟรมทุก 5 วิ แล้วเปิดดูว่าซับไม่ล้นจอ อ่านออก
4. short: hook ใน 2 วิแรก (v3: หัวข้อพูดจบใน 1.5 วิ ดูข้อ 9), ≤60 วิ, ซับไม่อยู่ใน 20% ล่าง
5. ภาษาอังกฤษเป็นธรรมชาติ ไม่ใช่แปลตรงตัว
6. ซับและภาพปกใช้ฟอนต์จาก `assets/fonts/` (v3: ฟอนต์ตาม look.json ใน `video/fonts/` ถือว่าผ่าน) ภาษาไทยไม่มีสระหรือวรรณยุกต์ลอย/ทับกัน มีภาพปกครบทุกภาษา
7. (ช่องที่มีกฎ "Motion เพิ่ม") ดึงเฟรมทุก 0.25 วิ เทียบคู่ติดกัน ห้ามช่วงภาพเหมือนเดิมเกิน 0.5 วิ
8. ทุกเพลงใน CREDITS.md เป็น CC0 หรือ CC BY และ `upload.md` มีเครดิตครบ

9. **เช็กลิสต์ตัดต่อ v3** (ตอนตั้งแต่ 2026-11-22; กฎใน `channels/<channel>/style.md` ทิศทาง 2026-11-22 และ `docs/editing-v3.md`) เขียนหัวข้อ `## เช็กลิสต์ตัดต่อ v3` ใน review.md ทีละข้อ ผ่าน/ไม่ผ่าน + หลักฐาน:
   - [ ] **Hook:** ดึงเฟรม 0.0 วิ: มีคำถามบนจอ + ภาพที่ทำให้แปลกใจ ไม่มีโลโก้/คำทักทาย/ปูพื้น; `python3 tools/pacing.py <project>` บรรทัด `topic ... said by` ≤ 1.5 วิ;
     **เทสต์ปิดเสียง (สำคัญสุด):** ดูเฟรม 0-1 วิแบบไม่ฟัง ต้องบอกได้ภายใน 1 วิว่าคลิปเรื่องอะไร + อยากรู้คำตอบไหม (ถ้าไม่ = ไม่ผ่าน); script.md มี hook 3 แบบ
   - [ ] **ความยาว:** 20-40 วิ หรือมี `long_reason` ใน shots.json ที่ฟังขึ้น (ไม่เกิน 59 วิ) — `tools/pacing.py` ไม่มี FAIL เรื่องความยาว
   - [ ] **ลูป:** ต่อ 2 วิท้ายเข้ากับ 2 วิแรกแล้วดู (`ffmpeg -sseof -2 -i X.mp4 -t 2 tail.mp4; ffmpeg -t 2 -i X.mp4 head.mp4` แล้ว concat) ภาพต้องไม่กระตุก/เปลี่ยนฉากแข็ง;
     เทียบเฟรมสุดท้ายกับเฟรม 0 ด้วยตา; อ่านประโยคสุดท้ายต่อด้วยประโยคแรกใน script.md ต้องลื่น และแต่ละประโยคจบในตัว
   - [ ] **โครงจังหวะ:** `tools/pacing.py` ไม่มี FAIL; เฉลย (reveal) เริ่ม ~50-60% (ตำนาน: หักมุมช่วง 30% ท้าย); มีหักมุม/ข้อแถม 1 ข้อหลังเฉลย; มีข้อเท็จจริงน่าส่งต่อ 1 ข้อก่อนจบ; ปิดด้วยคำถามชวนคอมเมนต์ ≤4 วิ
     และดูว่า beat ใน shots.json ตรงกับเนื้อหาจริง (ช็อตที่ติดป้าย reveal ต้องเป็นตอนเฉลยจริง)
   - [ ] **จังหวะตัด (แล้วแต่คลิป, style.md ข้อ 4):** ดูด้วยตาว่าจังหวะเข้ากับเนื้อหา ไม่ยืด ไม่มีเฟรมนิ่ง >0.5 วิ ทุกการตัดเป็นภาพ/มุมใหม่จริง; มี `"pace"` ใน shots.json อธิบายเหตุผล (INFO ของ pacing.py เรื่องความยาวช็อต = ข้อมูลประกอบ ห้ามตีตกเพราะข้อนี้อย่างเดียว);
     ซับ 1-3 คำต่อจังหวะ มีไฮไลต์คำสำคัญ
   - [ ] **หน้าตาไม่ซ้ำ:** `git fetch origin 'refs/heads/claude/ep-*:refs/remotes/origin/claude/ep-*'` แล้ว `python3 tools/look.py check <project> --final` ต้อง `look: OK`
     (แนบรายชื่อตอนที่เทียบ); เปิดเฟรม 0 / 50% เทียบกับตอนก่อนหน้า ต้องเห็นว่าสี/ฟอนต์/ซับ/โครงเปิดต่างกันจริง (ไม่ใช่แค่ใน look.json);
     ใช้ `templates/brainrot-v3/` (index.html มีบรรทัด `<!-- look: ... -->` ตรง look.json); เพลงใน MP4/CREDITS.md = `music_file`, เสียงพากย์ = `voice`;
     ข้อความเฟรม 0 = `cover_text` และไม่ซ้ำ/คล้ายปกตอนก่อน (look.py เช็กให้ แต่ดูภาพเทียบด้วย); ซับทุกก้อนอ่านออกบนพื้นของมัน
