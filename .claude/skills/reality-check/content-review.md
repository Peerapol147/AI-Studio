# Reality check สำหรับงานทำคลิป

## 1. ลำดับความน่าเชื่อถือของแหล่ง (สูง → ต่ำ)
1. systematic review / meta-analysis, แนวทางเวชปฏิบัติ (WHO, NHS, CDC, ราชวิทยาลัย)
2. งานทดลองที่มีกลุ่มควบคุม (RCT) ตีพิมพ์ peer-review
3. งานสังเกต/สำรวจ ตีพิมพ์ peer-review (ระวัง: สหสัมพันธ์ ≠ เหตุ)
4. ตำรา, เว็บมหาวิทยาลัย/โรงพยาบาล, ผู้เชี่ยวชาญอธิบายงานวิจัย
5. ข่าววิทยาศาสตร์ (ต้องตามไปหางานต้นฉบับ)
6. บล็อก, Wikipedia (ใช้หาต้นทางเท่านั้น), คลิป viral, คอมเมนต์ — **ห้ามใช้เป็นหลักฐาน**
ตัวเลข/สถิติ: ต้องได้จากระดับ 1-4 อย่างน้อย 1 แหล่ง หรือระดับ 5 สองแหล่งที่ชี้ต้นทางเดียวกัน
งานวิจัยชิ้นเดียว/กลุ่มตัวอย่างเล็ก/ในสัตว์: ต้องบอกในบท ("งานวิจัยหนึ่งพบว่า...", "ในหนูทดลอง...")

## 2. ป้ายต่อประโยค (researcher เขียนใน research.md, reviewer ตรวจกับ script.md)
| ป้าย | เงื่อนไข | วิธีพูดในบท |
|---|---|---|
| ✅ ยืนยัน | ระดับ 1-3 สอดคล้องกัน | พูดตรงๆ ได้ |
| ⚠️ ยังถกเถียง | งานวิจัยขัดกัน / มีชิ้นเดียว / ทำซ้ำไม่ได้ | "งานวิจัยบางชิ้นพบว่า..." หรือเปลี่ยนเป็นคำถามปิดท้าย |
| ❌ ไม่มีหลักฐาน / ความเชื่อ | หาแหล่งระดับ 1-4 ไม่ได้ หรือหลักฐานค้าน | ใช้เป็นฝั่ง "ความเชื่อ" เท่านั้น ห้ามพูดเป็นข้อเท็จจริง |
เรื่องสุขภาพ: ห้ามแนะนำยา/วินิจฉัย, ต้องมีประโยค "ถ้าเป็นบ่อย/รุนแรง ปรึกษาแพทย์" เมื่อเกี่ยวกับอาการ
ตัวเลขบนจอ/ในกราฟิก (รวมตัวนับที่วิ่ง) ต้องมีป้าย ✅ เท่านั้น

## 3. อ่านสถิติช่อง (ห้องวางแผน, ผู้กำกับ)
- ห้ามสรุปแนวโน้มจาก < 3 คลิป หรือคลิปอายุ < 48 ชม. → บอกว่า "ข้อมูลยังน้อย" + บอกว่าต้องรออะไร
- เทียบคลิปที่อายุเท่ากัน (วิวที่ 48 ชม. / 7 วัน) ไม่เทียบยอดสะสม
- ตัวชี้วัดหลัก: Stayed to watch % (hook), ดูเฉลี่ย ÷ ความยาว (ช่วงกลาง), ไลก์/วิว, คอมเมนต์/วิว
- ระวังตัวแปรปน: เวลาลง, ปก, ความยาว, วันในสัปดาห์, คลิปลงติดกัน — เปลี่ยนทีละอย่างเวลาทดลอง
- ผลเปลี่ยนจากข้อสรุปเดิม → บอกตรงๆ ว่าข้อสรุปเดิมผิด (ตัวอย่าง: เคยสรุปว่าสัตว์แพ้ แล้ววอมแบตขึ้นอันดับ 1)

## 4. ระดับความรุนแรง (ใช้ใน review.md)
| ระดับ | ตัวอย่าง | ทำอะไร |
|---|---|---|
| 🔴 ต้องแก้ก่อนส่ง | ข้อมูลผิด/เกินหลักฐาน, ลิขสิทธิ์/ไลเซนส์, โลโก้, ภาพไม่ตรงบท, เสียงเงียบ/ดำ, ซับผิด, placeholder ค้าง | แก้ + เรนเดอร์ใหม่ |
| 🟡 ควรแก้ถ้าไม่ต้องเรนเดอร์ | ข้อความ upload, เครดิต, ชื่อคลิป | แก้ไฟล์ข้อความ |
| ⚪ เก็บไว้ตอนหน้า | ความสวยงาม, ซับเกิน 3 คำนิดหน่อย, timing ต่าง < 0.2 วิ | จดใน lessons.md ไม่เรนเดอร์ใหม่ |
ทุกข้อในผลตรวจ: ฉาก, เวลา, ปัญหา, ระดับ, หลักฐาน (เฟรม/ลิงก์/ค่าที่วัด), agent ที่ต้องแก้
