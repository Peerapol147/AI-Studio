# ถอดสูตร: การ์ตูน "ออเดอร์ตีสาม" (2026-11-20)

ที่มา: ไฟล์ที่ผู้ใช้ส่งมา 17:09 นาที 1280x720 30fps (ไฟล์ต้นฉบับไม่เก็บใน repo)
สถานะ: **เรียนรู้เท่านั้น ยังไม่ลงมือทำ** (ผู้ใช้สั่ง "ยังไม่ต้องลงมือจนกว่าจะเชี่ยวชาญ")

## 1. มันคืออะไร
การ์ตูนผีไทยแบบเล่าเรื่องยาว ภาพแบน (flat vector) ตัวละครเรขาคณิต เล่าด้วยเสียงบรรยาย + ซับไทยตลอด เพลงคลอทั้งเรื่อง (ไม่มีช่วงเงียบเลย, ดัง -12.7 LUFS)
เรื่อง: "เจ" ไรเดอร์กะดึก ได้ออเดอร์ข้าวต้มกุ้ง 2 ชามไปบ้านเลข 9 ที่ไฟไหม้ไปแล้ว (แม่-ลูกตายในบ้าน) → ส่ง 3 คืน → สืบ → พบความจริง → ปิดด้วยความอบอุ่น/หลอนเบาๆ

## 3. ภาษาภาพ (วิธีเล่า)
- **มุมกล้อง 3 แบบวนไป:** ไกล (ฉากเต็ม ตัวเล็ก) → ใกล้ (หน้า/ครึ่งตัว ฉากหลังเบลอ) → แทรกของ (มือถือ ชาม ถุง กุญแจ บ้านเลข 9)
- **จอมือถือเป็นตัวเล่าเรื่องหลัก:** ออเดอร์เข้า เวลา 02:48 แชตลูกค้า หักเงิน 30 บาท — ข้อมูลอยู่ในจอ ไม่ต้องพูด
- **ป้ายลอย (HUD) มุมซ้ายบน:** "สี่วันก่อน", "22:00", "ครั้งที่ 3", "-30 บาท", "3 คืนติด", "1 ปี" + ป้ายชื่อตัวละคร ("เพื่อนสนิท บอย") ตอนเปิดตัว
- **ตัดภาพทุก ~5-7 วิ** (เปลี่ยนฉากชัดๆ 140 ครั้งใน 17 นาที) + กล้องดันเข้าช้าๆ เกือบทุกช็อต + ตัวเดิน/ขี่รถด้านข้าง ฉากเลื่อน
- **ของซ้ำเป็นสัญลักษณ์:** ชามใหญ่-ชามเล็ก, มือเล็กจับนิ้ว, ถุงข้าวต้ม, บ้านเลข 9 → กลับมาตอนจบ
- **ซับ:** ขาว ตัวหนา กลางล่าง เงาดำ ทีละประโยค

## 4. โครงเรื่อง (ใช้ได้ทันที)
1. **0:00-0:28 เปิดด้วยฉากหลอนที่สุดก่อน** ("อย่าเพิ่งกดครับ" + มือเล็กจับนิ้ว) = hook
2. 0:28 ชื่อเรื่องตัวแดงเรือง "ออเดอร์ตีสาม 03:00 น."
3. ย้อน "สี่วันก่อน" ปูชีวิตตัวเอก + กฎของตัวเอง ("ตัวเลขที่สำคัญที่สุดไม่ใช่เงินในบัญชี แต่คือดาว")
4. ทำซ้ำ 3 รอบ (คืน 1-2-3) แต่ละรอบเพิ่มความหลอน 1 อย่าง → กติกา 3 ครั้งแบบนิทาน
5. สืบ (ป้าข้างบ้าน ข่าวเก่า ช่างซ่อมรถ) → เฉลย → จบอบอุ่นปนหลอน

## 6. ถ้าจะทำจริง (ยังไม่ทำ) — ทำได้ด้วยเครื่องมือที่มี
- ภาพแบนแยกชั้นได้ = **ทำด้วยโค้ดได้เกือบ 100%** (ต่างจากอนิเมะวาดมือที่ต้อง AI) ตามคู่มือ hyperframes `types/character.md` + reverse-any-video `animated.md` ข้อ "code"
- ต้องสร้างก่อน 1 ครั้ง แล้วใช้ซ้ำทุกตอน: (1) ชุดตัวละคร SVG + ท่า/อารมณ์ (2) ชุดฉากไทย (ซอย ร้านสะดวกซื้อ ห้องเช่า บ้านร้าง) (3) จอมือถือ + ป้าย HUD (4) กล้อง (ดันเข้า เลื่อนข้าง เบลอฉากหลัง)
- ข้อควรระวังจากคู่มือ: อย่าขยับทุกส่วนพร้อมกัน (หัวนำ แขนตาม), กระพริบตา/หายใจตอนนิ่ง, เปลี่ยนอารมณ์ต้องมีจังหวะ ไม่สลับทันที
- จุดที่ "สวยกว่า" ได้: เพิ่มเส้นสั่นแบบวาดมือ (redraw 12 ครั้ง/วิ) , แสงสีอุ่น-เย็นตัดกัน, ฝุ่น/ละอองในแสงไฟ
- เสียง: บรรยายเทคเดียว (โควตา ElevenLabs เหลือน้อย) + เพลงคลอ + SFX (ประตู ไฟไหม้ แจ้งเตือนแอป)
- 9:16: ช็อตใกล้ใช้ได้เลย ช็อตไกลต้องจัดฉากแนวตั้งใหม่
- ยังไม่รู้: เสียงบรรยายเป็น AI หรือคน (ยังไม่ได้ถอดเสียง เพื่อประหยัดโควตา)

## 7. บทเรียนจากคลิปสอน "Claude AI Made This 3D Animation With Code" (The Wealthy AI, 125K วิว, 2026-11-05)
ที่มา: https://www.youtube.com/watch?v=rzxeaKXTiQA (ถอดซับผ่าน Apify) — เขาทำสไตล์ "ฉาก 3D จริง + ตัวละคร 2D แบน" (ต้นแบบช่องใหม่ได้ 29M) ด้วย Claude + Remotion
ขั้นตอนของเขา → ที่เราจะใช้:
1. **สอนสไตล์จาก 10 คลิปจริง** ไม่ให้เดา → ให้ดูทีละเฟรม (กล้อง การตัด สี แสง แพทเทิร์นบท) แล้วเขียนลง "rulebook" ไฟล์เดียว ⇒ เรามีต้นแบบแค่ 1 คลิป ต้องหาเพิ่มให้ครบ ~10 คลิปในสไตล์ที่ผู้ใช้อยากได้
2. **บท:** ทุกคลิปไวรัลเปิดด้วย "เรื่องที่ฟังดูเป็นไปไม่ได้" แล้วค่อยอธิบาย (= สูตร D ความเชื่อ vs ความจริงของเรา)
3. **ภาพ: ทำ "เฟรมนิ่ง 1 เฟรม เทียบข้างกันกับต้นแบบ" ก่อน** แก้ทีละจุด (เส้นบาง/หนา เงาแรง มือถือเหลี่ยมไป) จนเหมือน → ค่อยทำภาพเคลื่อนไหว (ทำวิดีโอเลย = ได้กล่องสี่เหลี่ยมจืดๆ)
4. **ทดสอบเคลื่อนไหว 5 วิ ด้วยสเปกละเอียด** ไม่ให้เดา: ฉากหน้า-กลาง-หลัง, ฉากหลังเบลอ ตัวละครคม, เส้นหมึกทุกขอบ, กล้องเคลื่อนผ่านโลก
5. **เรนเดอร์ช้า:** เครื่องคลาวด์ไม่มีการ์ดจอ 5 วิใช้ 13 นาที (ความละเอียดต่ำ) → เขาเรนเดอร์บนโน้ตบุ๊ก RTX เหลือ 1 นาที
   ⇒ ของเรา: เรื่องยาว 5-8 นาทีเรนเดอร์บนคลาวด์อาจใช้หลายชั่วโมง → แบ่งท่อน + เรนเดอร์หลายห้องพร้อมกัน หรือเรนเดอร์บนเครื่องผู้ใช้ (ถ้ามีการ์ดจอ, ผ่าน Remote Control)
6. ไม่ต้องขอ "master file" ของเขา (ต้องคอมเมนต์แลก) — เราสร้าง rulebook เองด้วยขั้น 1+3
