ห้องวางแผน Creative #2 เขียนตอนผู้ใช้สั่ง "เทรนตัวเองเรื่องการสร้างแนวคิดและสตอรี่ ขัดเกลา เตรียมตัวโปรเจกต์ใหญ่"

## 2. กฎเล่าเรื่อง 12 ข้อ (ใช้ทุกบท)
1. **เรื่องเดียว หักมุมเดียว** เล่าได้ในประโยคเดียว: "X คิดว่า __ แต่จริงๆ __" ถ้าเล่าประโยคเดียวไม่ได้ = ยังไม่ใช่เรื่อง
2. **ภาพแรกต้องเป็นปัญหา** ไม่ปูพื้น ไม่แนะนำตัว (ออเดอร์ตีสามเปิดด้วยฉากหลอนสุดก่อน; ค่ายลูกเสือเปิดด้วยเดินในป่ามืด)
3. **ปู 70 / หักมุม 30** (บทเรียนผีอำ 781 วิว: หักมุมเร็วเกิน = แป้ก)
4. **กติกา 3 ครั้ง:** ครั้งแรกตั้งกติกา ครั้งสองย้ำ ครั้งสามพลิก (นับ 1-5 → "6"; คืน 1-2-3 ออเดอร์ตีสาม)
5. **ผีต้องอยากได้อะไรสักอย่างแบบคน** (กระสืออยากกินไก่, ผีอยากให้คนจำได้) → คนดูเข้าใจผีได้ = ตลกหรือสะเทือนใจได้
6. **หักมุมต้องเปลี่ยนความหมายของสิ่งที่เห็นไปแล้ว** ไม่ใช่เพิ่มข้อมูลใหม่ (ครูพาเด็กเข้าห้องลับ = ตอนแรกน่ากลัว พอเฉลยกลายเป็นน่ารัก)
7. **ของชิ้นเดียวเป็นเส้นเรื่อง** ถือไปจนจบ (ชามข้าวต้ม, มือถือ, นกหวีดลูกเสือ) — ตามคู่มือ story.md "one real piece of data travels"
8. **ให้ภาพเล่า เสียงไม่พูดซ้ำภาพ** จอมือถือ ป้ายมุมจอ หน้าตัวละคร
9. **ตัดภาพทุก 1.5-3 วิ ในคลิปสั้น** (ออเดอร์ตีสาม 5-7 วิ เพราะยาว 17 นาที — ใช้ไม่ได้กับ Shorts)
10. **อารมณ์อยู่ที่หน้าตัวละคร** หยุดค้างหน้าตอนรีแอคท์ ½-1 วิ (คู่มือ character.md: "hold the reaction")
11. **จบให้วนได้** ประโยคสุดท้ายต่อกับภาพแรก หรือจบด้วยภาพที่ทำให้อยากย้อนดู (Shorts วนอัตโนมัติ)
12. **ปิดด้วยคำถาม 2 ทางที่ตอบง่าย** ("ถ้าเป็นเรา จะนับต่อไหม") ห้าม "ไม่กด = ซวย" (engagement bait)

## 4. ขัดเกลาบท (เช็กลิสต์ — ใช้ทุกครั้งก่อนอัดเสียง)

## 5. แบบฝึก: บทตัวอย่าง 6 เรื่อง (ร่าง — ยังไม่ผ่านผู้ใช้ ยังไม่ทำ)
ทุกเรื่องคิดใหม่ ไม่ลอกพล็อตใคร ใช้ตัวเอก "เจ" แบบไรเดอร์ก็ได้ หรือตัวละครประจำช่องที่จะออกแบบ

**1. "ปอบฝึกงาน" (สูตร A, ~38 วิ)** — ประโยคเดียว: ทั้งหมู่บ้านคิดว่าบ้านท้ายซอยมีปอบเพราะไก่หายทุกคืน แต่ปอบที่นั่นเป็นมือใหม่ กินไก่ไม่เป็นเลย เอาไปเลี้ยงไว้ข้างหลังบ้าน
- 0-2 วิ: ภาพเล้าไก่ว่าง ขนไก่ปลิว ป้ายมุมจอ "ไก่หาย คืนที่ 3"
- บท: "ไก่บ้านป้าศรีหายอีกแล้ว สามคืนติด / ทุกคนชี้ไปบ้านเดียว บ้านท้ายซอยที่ไฟเปิดทั้งคืน / คืนนี้ลุงแดงถือไฟฉายไปส่อง… / ได้ยินเสียงกุกกัก / แล้วก็เห็นผู้หญิงผมยาว นั่งยองๆ อยู่กลางไก่ยี่สิบตัว / …กำลังป้อนข้าวสารให้ทีละตัว / 'ก็เขาบอกว่าปอบต้องกินไก่… แต่หนูทำไม่ลงอะ'"
- ปิด: "ถ้าเจอปอบแบบนี้ จะไล่หรือช่วยเลี้ยงไก่"
- ⚠️ เลี่ยงความรู้สึก "ชาวบ้านไล่คนบริสุทธิ์" ให้ขำ ไม่ให้เจ็บ

**2. "นับขั้นบันได" (สูตร B, ~15 วิ)** — ประโยคเดียว: เด็กหอพักนับขั้นบันไดตอนตีสามทุกคืนได้ 12 แต่คืนนี้นับลงได้ 13
- 0-2: เท้าก้าวลงบันไดมืด เลขลอย "1"
- นับไปเรื่อยๆ ภาพตัดตามเท้า … "12" … เท้ายังก้าว … "13" — ภาพค้างที่เท้าที่สอง ที่ไม่ใช่เท้าเรา
- ประโยคเดียวท้าย: "เดี๋ยว… ใครเดินตามมาวะ"
- ปิด: "นับต่อ หรือวิ่ง" / จบให้วน: ภาพตัดกลับไปขั้นที่ 1

**3. "กระสือลดน้ำหนัก" (สูตร C, ~30 วิ)** — ประโยคเดียว: กระสือตั้งใจไดเอท ทุกคืนบินผ่านร้านหมูกระทะ 3 ร้าน
- คืน 1 ร้านแรก: หันหน้าหนี ✓ / คืน 2 ร้านที่สอง: แอบดม ✓ / คืน 3 ร้านสาม: ไส้ไปพันตะแกรงหมูกระทะ ดึงไม่ออก ป้าเจ้าของร้านเขี่ยให้ด้วยตะเกียบ
- ปิด: "ไดเอทพังแบบนี้ เคยเป็นไหม"

**4. "ทำไมห้ามตัดเล็บตอนกลางคืน" (สูตร D, ~30 วิ) — สูตรช่อง knowledge ที่พิสูจน์แล้ว** — ความเชื่อ: ตัดเล็บกลางคืน ผีมาเอาเล็บ / ความจริงที่ต้องตรวจ: สมัยไม่มีไฟฟ้า กรรไกรตัดเล็บเป็นมีดคม มืดๆ ตัดโดนเนื้อ
- (ต้องผ่าน researcher ก่อน ห้ามแต่งข้อเท็จจริง)

**5. "ผีเฝ้าห้องเช่า" (สูตร E, ~39 วิ)** — ประโยคเดียว: เจย้ายเข้าห้องเช่าที่มีผียายแก่บ่นทุกเรื่อง (ปิดไฟ ล้างจาน) จนเจไปจ้างพระมาไล่ แต่คืนที่ไฟช็อตไหม้ ยายปลุกเจทัน
- จบ: ห้องใหม่ เจตั้งน้ำแดงไว้มุมห้อง "ยายครับ ปิดไฟแล้วนะ"
- ใช้ลายเส้น/ฉากห้องแบบออเดอร์ตีสามได้ตรงๆ

**6. "ออเดอร์ตีสาม ฉบับ 40 วิ" (สูตร A+E)** — ฝึกย่อเรื่อง 17 นาทีให้เหลือ 40 วิ (ไม่ใช้พล็อตเขา แค่ฝึกย่อ): ไรเดอร์ได้ออเดอร์ข้าวต้ม 2 ชาม "ชามเล็กไม่ใส่ขิง" ไปบ้านที่ไม่มีคน คืนที่ 3 มีมือเล็กๆ รับถุง → เฉลยด้วยภาพเดียว: รูปแม่-ลูกบนหิ้งพระ ข้างรูปมีชามเล็ก
- บทเรียน: เรื่อง 17 นาทีย่อได้ เพราะแก่นคือ "ของชิ้นเดียว (ชามเล็ก) + 3 คืน + ภาพเฉลยภาพเดียว"
