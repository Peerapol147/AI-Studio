## ข้อเสนอ 1: ความยาวยืดหยุ่นตามเนื้อหา (แทนเป้าตายตัว 15-20 วิ) — สถานะ: รอ approve
ที่มา: ผู้ใช้ต้องการให้ความยาวตามเนื้อหา + ข้อมูล 2026-11-19 (results.md):
ผู้สูงอายุ 30 วิ ดูได้ 76% ของความยาว / น้ำอัดลม 40 วิ 30% / ธรรมชาติ 43 วิ 40% → คนหลุดเพราะช่วงยืด ไม่ใช่เพราะยาว

กฎใหม่ที่เสนอ (แก้ style.md + make-clip เมื่อ approve):
- ไม่มีเป้าวินาทีตายตัว ช่วงที่อนุญาต 15-50 วิ (Shorts ≤60 วิ ตาม CLAUDE.md)
- ความยาวมาจากโครง: hook (≤2 วิ) → ความเชื่อ → หักมุม/กลไก → payoff → คำถามปิด
  เนื้อหาที่มี "หักมุมเดียว" = 15-25 วิ; มีหลายชั้น/เรื่องเล่า = 30-50 วิ
- ทดสอบตอนเขียนบท: ทุกประโยคต้องตอบได้ว่า "ถ้าตัดออก คนดูเสียอะไร" ถ้าไม่เสีย ตัด
- ทุก 5-7 วิ ต้องมี "ตะขอเล็ก" (คำถามใหม่ ภาพเปลี่ยน ตัวเลขช็อก) กันหลุดกลางคลิป
- เกณฑ์วัดหลังลง: % ดูของความยาว ≥70% และ Stayed to watch ≥70% ถ้าคลิปยาวกว่า 30 วิ แล้วต่ำกว่านี้ = ยืดเกิน

สิ่งที่ต้องเพิ่ม (สมมติฐาน ต้องพิสูจน์ด้วยข้อมูลช่องเอง):

## ข้อเสนอ 4: Layout มาตรฐาน 1080x1920 (ผู้ใช้ 2026-11-19: ให้ห้องนี้ดูแล layout) — สถานะ: รอ approve
ที่มา: คู่มือ safe zone จากบุคคลที่สาม (ไม่มีสเปกทางการ ตัวเลขวัดจาก UI แอป ต่างกันตามแหล่ง) ใช้ค่าที่เข้มสุดให้ผ่านทั้ง YT/TikTok/Reels
| โซน | Y (px) | ใช้ทำอะไร |
|---|---|---|
| ห้ามข้อความ (UI บน) | 0-220 | ภาพพื้นหลังเท่านั้น |
| หัวเรื่อง/hook | 240-700 | คำถามตัวใหญ่ (tag "รู้ไหม?" ต้องเริ่มที่ ≥240) |

| ซับ | 1100-1300 | (ตอนนี้ 1190 ✅) |

| ห้ามข้อความ (ชื่อคลิป/ปุ่ม) | 1440-1920 | |
| ราง ไลก์/คอมเมนต์/แชร์ ขวา | X>900, Y≥840 | ห้ามวางวงกลม inset/ข้อความสำคัญ |
ขอบซ้าย-ขวา: Y<840 ≥60 px; Y≥840 ข้อความอยู่ใน X 120-900 (ซับกว้างสุด 780 px)
อัปเดต 2026-11-19 วัดเผื่อ TikTok + Facebook Reels: TikTok (template โฆษณา) บน 240/ข้าง 120/คอลัมน์ปุ่มขวา 180 px เริ่ม Y 840;

→ ตารางนี้ = ค่าที่เข้มที่สุดของ 4 แพลตฟอร์ม
กฎเสริม (คำแนะนำจากบล็อก ไม่มีหลักฐานแน่น):
- คนดูช่วงแรกปิดเสียง: ข้อความ hook บนจอ = คำพูด hook คำต่อคำ
- ภาพ/แผนภาพซับซ้อน → ซับสั้นลง (≤2 คำ) กันข้อมูลล้น
- การทดลอง layout (เปลี่ยนทีละอย่าง): A = คำถามแสดงแค่ 2 วิแรก (แบบเดิม) vs B = แถบคำถามค้างบนจอทั้งคลิปที่ Y 240-400 (คนที่เข้ามากลางลูปรู้ทันทีว่าเรื่องอะไร)
