| ทำไมไปคนเดียว | บริษัทเอกชนลดต้นทุน ส่งคนเดียว (ตัวละครหัวหน้าพูดในวิทยุตอนต้น) |

| สิ่งมีชีวิตโผล่มาลอยๆ | **ปูใบ้ 2 ครั้ง:** ท่อน 2 ข้อมูลดาวเทียม "เซนเซอร์กะพริบไม่ทราบสาเหตุ"; ท่อน 4 ตอนออกนอกยาน เห็นประกายเหมือนฝุ่นเรืองแสงไหลผ่าน |
| เสียงในอวกาศ | เสียงเคาะได้ยิน "ผ่านตัวยาน" (มันแตะผนัง) — โชว์ภาพผนังสั่น ฝุ่นในยานกระเด้ง |

### จุดที่จะไม่บันเทิงใน v1 → แก้
1. **คนเดียวในห้องแคบ 5 นาที = ภาพซ้ำ น่าเบื่อ** → เพิ่มที่ที่ไปได้: ห้องโดยสาร / นอกยาน (EVA) / มองโลกขึ้นจากขอบดวงจันทร์ / ภาพย้อนความทรงจำบ้านแม่ (ตลาด ร้านข้าวต้ม) / สถานี "ศาลา"
2. **ไม่มีใครให้คุยด้วย = บรรยายล้วน** → เพิ่ม **ผู้ช่วยในยานราคาถูก "น้องปลาทู"** เสียงหุ่นยนต์ใจดีแต่ทื่อ พูดถูกจังหวะผิดเวลา (ท่องคู่มือ "กรุณาให้คะแนนการเดินทาง" ตอนยานกำลังพัง) = มุกตลก + ช่วยอธิบายข้อมูลแทนผู้บรรยาย; ช่วงสิ้นหวังแบตใกล้หมด น้องปลาทูต้องถูกปิดเพื่อประหยัดไฟ = ฉากเศร้าที่สุด (บอกลาเพื่อนคนเดียว)
3. **เดิมพันไม่พอ** → ต้นรับงานนี้เพราะเงินพิเศษใช้หนี้ค่ารักษาแม่; บะหมี่ซองนั้นแม่ใส่กระเป๋าให้ = ของจากบ้าน
4. **ต้องมีชนะเล็กๆ ระหว่างทาง** (ไม่ลงอย่างเดียว): อุดรอยรั่วได้ (ชนะ) → ปรับยานหันได้ (ชนะ) → แต่ไม่พอ (แพ้)
5. **มุกเล็ก + ดีเทลไทย** ให้คนดูแชร์: ป้ายยาน "ปลาทู-1" ต้นแปะพระเครื่องกับรูปแมวไว้บนแผงควบคุม ซองบะหมี่ลอยในยาน เทปพันสายไฟสีดำ "ซ่อมได้ทุกอย่าง"

## v3 โทน (ผู้ใช้ 2026-11-20): "สมจริงผสมไซไฟ สนุก ร่วมลุ้น ระทึก"
- สมจริง (researcher ต้องยืนยันทุกข้อ ห้ามแต่งตัวเลข): ด้านไกลดวงจันทร์ติดต่อโลกตรงไม่ได้ ต้องพึ่งดาวเทียมรีเลย์ (มีของจริง); ภัยจริงคือ CO2 สะสม (ปวดหัว หายใจหอบ สับสน) ไม่ใช่แค่ O2 หมด; หนาว; หยดน้ำ/เหงื่อลอยเป็นลูก; เศษขยะเร็วระดับ กม./วินาที; ชุดอวกาศมีถังสำรองจำกัด
- ไซไฟ (เรื่องแต่ง ทำให้ฟังดูเป็นไปได้): สิ่งมีชีวิตที่กินน้ำแข็ง/แก๊ส อาศัยในหลุมอุกกาบาตที่ไม่เคยโดนแดด เรืองแสงสื่อสารเป็นจังหวะ
- ระทึก: นาฬิกานับถอยหลังบนจอตลอด; คนดูเห็นเงาสิ่งมีชีวิตก่อนต้น (dramatic irony); ตัดสลับกับสถานี "ศาลา" ที่เริ่มสังเกตความผิดปกติ; ทุกการตัดสินใจมีราคา; เสียงลมหายใจ หัวใจ ความเงียบ
