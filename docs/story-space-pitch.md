# เสนอเรื่อง: การ์ตูนอวกาศยาว ~5 นาที (2026-11-20, ห้อง Creative #2)
ผู้ใช้ขอ: อวกาศ, ชวนลุ้น, เอาตัวรอดด้วยของจำกัด, สิ้นหวัง, สุดท้ายโชคดี, อาจมีเอเลี่ยน
สถานะ: **รอผู้ใช้ approve** → แล้วส่งห้องเขียนเรื่อง

## ทางเลือก (แนะนำ A)
- **A. "เคาะสามที"** (แนะนำ: มีของจำกัดให้คนดูนับตามได้ + หักมุมที่เปลี่ยนความหมายของเสียงเคาะทั้งเรื่อง)
- B. "บ่อน้ำสุดท้าย" — ติดดาวทะเลทราย 2 คน คนนึงเจ็บ น้ำเหลือ 3 วัน รอดเพราะเจอรถสำรวจเก่าที่ยังส่งสัญญาณได้ (ลุ้นแต่ไม่มีเอเลี่ยน)
- C. "ยานลูกเดียว" — เด็กกับหุ่นยนต์เก่าตื่นมาบนยานที่ลูกเรือหายหมด (ลึกลับมากกว่าเอาตัวรอด)

## A. "เคาะสามที" — ประโยคเดียว
ช่างซ่อมดาวเทียมไทยติดอยู่ในแคปซูลพังหลังดวงจันทร์ ออกซิเจนเหลือ 9 ชั่วโมง ได้ยินเสียงเคาะนอกยานสามทีครั้งแล้วครั้งเล่า คิดว่าเป็นเศษขยะอวกาศ จนรู้ว่ามี "อะไรบางอย่าง" พยายามช่วยเขามาตลอด

ตัวละคร: **ต้น** (29) ช่างซ่อมดาวเทียม ไปงานเดี่ยวครั้งแรก ติดนิสัย "ทุกอย่างต้องมีแผนสำรอง" พกบะหมี่กึ่งสำเร็จรูปซองเดียวไว้ฉลองงานเสร็จ / ยาน **"ปลาทู-1"** แคปซูลขนของเล็กๆ / **แม่** (ได้ยินแค่เสียงในคลิปเสียงที่ต้นอัดไว้)
ของชิ้นเดียวที่ถือตลอดเรื่อง: **ตัวเลขออกซิเจนบนจอ** (นับถอยหลังทุกท่อน) + **เสียงเคาะ 3 ที**
ของจำกัด (คนดูนับตามได้): O2 9 ชม. / แบตเตอรี่ 3 ก้อน / น้ำ 1 ถุง / เทปพันสายไฟ 1 ม้วน / บะหมี่ 1 ซอง / เครื่องทำความร้อน 1 ตัว — แบต 3 ก้อนต้องเลือกระหว่าง วิทยุ / ความอุ่น / เครื่องฟอกอากาศ

## ข้อควรระวัง (ส่งต่อห้องเขียนเรื่อง)
- ห้ามคล้ายหนังดังใดๆ (ไม่ใช้ชื่อ ฉาก ประโยค หรือหน้าตาสิ่งมีชีวิตจากหนัง)
- ฟิสิกส์พอเชื่อได้ ไม่ต้องเป๊ะ แต่ห้ามผิดโจ่งแจ้ง: อวกาศไม่มีเสียง → เสียงเคาะต้องได้ยิน "ผ่านตัวยาน" (สั่นทะลุผนัง) ไม่ใช่ลอยมาในอากาศ; หลังดวงจันทร์ติดต่อโลกไม่ได้จริง
- เสียงพากย์ ~4,000-5,000 ตัวอักษร เกินโควตา ElevenLabs ฟรีที่เหลือ (~3,870 ก่อนห้อง Gen Z ใช้ไป) → ผู้ใช้ต้องตัดสินเรื่องจ่ายก่อนอัด
- สไตล์ภาพยังไม่เลือก (แบนล้วน หรือ ฉาก 3D + ตัว 2D) — บทใช้ได้ทั้งสองแบบ
