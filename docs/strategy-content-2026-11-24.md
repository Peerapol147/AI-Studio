## 3. โครงบทของ 4 คลิปยอดสูง **[ข้อเท็จจริง: จากซับอัตโนมัติ สะกดอาจผิด]**
ความเชื่อ → "แต่ความจริงคือ" → หลักฐานหรือกลไกที่ระบุได้ (หมอหักนิ้วมือซ้ายหลายสิบปี / ให้คนหายใจออกซิเจนบริสุทธิ์ / นักบินอวกาศ Chris Hadfield / ผนังลำไส้แข็งสลับนิ่ม) → ข้อควรระวังหรือ twist → คำถามปิด
- ความยาว 20–35 วิ ประโยคละ ~2.5 วิ
- ปิดด้วยคำถามที่ผู้ชมทำได้ทันที (หักนิ้ววันละกี่ที / ดูถึงตรงนี้หาวไปกี่ทีแล้ว) ได้คอมเมนต์ 24 และ 16 ส่วนคำถามเชิงสมมติ (จะลองตดในอวกาศไหม / ขี้เป็นเหลี่ยมเพื่ออะไร) ได้ 2 และ 1 **[สมมติฐาน]** คอมเมนต์ที่ต่างอาจมาจากปัจจัยอื่นด้วย
- ไลก์/วิว สูงสุดคือตด 3.2% (ไอเดียมีมุกชัด + twist) ที่เหลือ 1.5–2.7%

## 4. ข้อเสนอ (ล้วนเป็น [ความเห็น] ใช้หรือไม่ใช้ก็ได้)
1. **ทดสอบเฉลยเร็ว vs เฉลยกลาง** ในหัวข้อใหม่แนวเดียวกัน (เปลี่ยนตัวแปรเดียว) แล้วเทียบ "ดูเฉลี่ย ÷ ความยาว" ตามที่ results.md วัดอยู่แล้ว
2. **วัดซ้ำที่ 7 วัน** เพิ่มจาก 48 ชม. ก่อนสรุปว่าแนวไหนทิ้ง (ดู 2.1)
3. **หัวข้อ:** เรื่องที่คนทำเองหรือสงสัยเอง + มีมุกหรือภาพจำง่าย (หักนิ้ว, หาว, ตด, วอมแบต) ยังเป็นแนวที่ข้อมูลช่องสนับสนุนมากที่สุด; แนวตำนาน/ข่าว/รุ่นอายุ (ผีอำ 3,465, Gen Z 475, บั้งไฟพญานาค 115) ต่ำกว่า → แต่ 3 คลิปไม่พอสรุปว่า "แนวนี้ไม่ดี"
4. **คำถามปิดท้าย:** ลองแบบ "ทำได้ทันที/นับได้" สลับกับแบบสมมติ ดูว่าคอมเมนต์ต่างกันจริงไหม
5. **ใช้ข้อมูลสาธารณะคู่กับ Analytics:** ดึงวิว/ไลก์/คอมเมนต์ทุกวันได้ถูกๆ แต่ไม่เห็น retention, Stayed to watch, แหล่งที่มา ต้องใช้ภาพ Analytics ที่ผู้ใช้ส่งต่อไป

## 6. วิธีดึงข้อมูลซ้ำ (ไม่มี key ในไฟล์ proxy แนบให้เอง)
- Apify MCP (`mcp.apify.com`) Actor `streamers/youtube-scraper` ใส่ `startUrls` เป็น URL หน้าช่อง (`https://www.youtube.com/@handle` ไม่ต่อ `/videos`), `maxResults`, `maxResultsShorts`, `maxResultStreams`
