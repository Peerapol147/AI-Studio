# บทเรียนจากสถิติช่อง (ผู้ใช้อนุมัติแล้วเท่านั้น)

กฎ:
- ห้ามใส่ตัวเลขสถิติของช่อง (repo เป็น public) เขียนเป็นหลักการ เช่น "hook แบบถามคำถามคนดูอยู่ครบมากกว่า"
- เพิ่มได้เมื่อ insight ผ่านเกณฑ์ตัวอย่าง (≥10 คลิปต่อกลุ่ม อายุ ≥7 วัน) และผู้ใช้อนุมัติ
- ระบุวันที่และกลุ่มที่ใช้สรุปทุกข้อ
