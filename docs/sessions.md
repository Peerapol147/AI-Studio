# ทำงานหลายเซสชัน (1 เซสชัน = 1 ตอน)

เพื่อประหยัด token: แต่ละเซสชันทำคลิปตอนเดียว จบแล้วปิด ไม่ลากบทสนทนายาวข้ามตอน
ทุกอย่างที่ต้องรู้อยู่ใน repo แล้ว (CLAUDE.md, docs/pipeline.md, channels/*/style.md, .claude/agents/) ไม่ต้องอ่านประวัติแชต

## เริ่มตอนใหม่
1. เปิดเซสชันใหม่ด้วย repo AI-Studio
2. สั่งประโยคเดียว เช่น `ทำตอนใหม่: short ช่องความรู้ ไทย+อังกฤษ เรื่อง ...` หรือ `ทำตอนใหม่: ช่องความรู้ ให้ทีมคิดหัวข้อ`
3. เซสชันสร้าง branch ของตอน `claude/ep-<YYYY-MM-DD>-<slug>` และทำงานเฉพาะใน `projects/<YYYY-MM-DD>-<channel>-<slug>/`

## กฎกันชนกัน
- แต่ละตอนแตะแค่โฟลเดอร์โปรเจกต์ของตัวเอง
- ไฟล์ร่วม (`channels/`, `.claude/agents/`, `tools/`, `docs/`) แก้เฉพาะเมื่อผู้ใช้สั่ง และบอกผู้ใช้ทุกครั้ง
- หัวข้อที่ทำไปแล้ว/สำรองไว้: ดู `projects/*/brief.md` และ `projects/*/research-topics.md` ก่อนเลือกหัวข้อ ห้ามซ้ำ

## ประหยัด token ภายในตอน
- ผู้กำกับเช็ก key/เครือข่ายของแหล่ง footage และเสียงเอง (curl 1 ครั้ง) ก่อนสั่ง agent ถ้าติด บอกผู้ใช้ทันที ไม่ส่ง agent ไปลองเอง
- ผู้กำกับไม่อ่านไฟล์ใหญ่เอง (words.json, ภาพ) ให้ agent อ่านแล้วสรุปกลับ
- ตอบกลับจาก agent ให้สั้น (≤120 คำ) ตามที่สั่งไว้ใน prompt
- เรนเดอร์ใหม่เฉพาะเมื่อผู้ตรวจพบปัญหาจริง ไม่ใช่เรื่องเล็ก
- Pixabay key: ตั้ง `PIXABAY_API_KEY` ใน Environment variables ของ environment (ไฟล์ `.env` ไม่ติดไปเซสชันใหม่)

## หัวข้อสำรองช่องความรู้ (จาก research-topics.md ของตอนวอมแบต)
กุ้งดีดขัน (ฟองร้อน ~5,000 K), ฟลามิงโกเกิดมาสีเทา, ลายนิ้วมือโคอาล่า (ระวังข่าวลือเรื่องตำรวจ)
