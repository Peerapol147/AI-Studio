# สรุปโปรเจกต์ AI Studio (สำหรับส่งต่อให้ AI ตัวอื่นอ่าน) — อัปเดต 2026-11-23

> ตัวเลขทุกตัวในไฟล์นี้คัดจาก `channels/knowledge/results.md` (จดจากภาพ YouTube Studio ที่เจ้าของช่องส่งมา) ไม่ได้ประมาณเอง
> ป้ายความน่าเชื่อ: ✅ = ข้อมูลจริงของช่อง / 🔎 = แหล่งภายนอกที่ค้นแล้ว / ❓ = สมมติฐาน ยังไม่พิสูจน์

## 1. โปรเจกต์คืออะไร
- ทีม AI (Claude Code หลายห้องทำงานพร้อมกัน) ผลิตคลิปสั้นภาษาไทยอัตโนมัติ เจ้าของช่องแค่สั่งหัวข้อแล้วอัปโหลด MP4 เอง
- ช่องหลัก: **ความรู้ทั่วไป (knowledge)** เป็น YouTube Shorts 9:16 ภาษาไทย ไม่มีหน้าคน (faceless) ใช้เสียงพากย์ AI (ElevenLabs) + ภาพสต็อกฟรี + กราฟิกเคลื่อนไหว + ซับไทยบนจอ
- มีช่องฟุตบอลอีกช่อง (ทำไป 1 คลิป ยังไม่ได้ตัดสินว่าลงช่องไหน)
- **เป้า:** 10 ล้านวิว YouTube Shorts ภายใน 17 ธ.ค. 2026 (เจ้าของรู้ว่าโอกาสต่ำมาก ต้องราว 370K วิว/วัน แต่ไล่เต็มที่)
- งบต่อคลิป ≤ $10-15; เสียงพากย์ใช้ ElevenLabs (เคยเป็น free tier ซึ่งใช้หารายได้ไม่ได้ ต้องอัปเกรดก่อนเปิดรายได้)
- ข้อห้าม: ภาพหนัง/ละคร/ข่าว/ไฮไลต์บอล/โลโก้, เพลงติดลิขสิทธิ์, เนื้อหาพนัน; ข้อเท็จจริงต้องมาจากแหล่งที่ตรวจแล้วเท่านั้น

## 2. วิธีทำงาน (สายพาน)
1. ห้องวางแผน: เลือกหัวข้อจากยอดวิวคลิปคู่แข่ง (เกณฑ์: Shorts ไทย ≥100K หรือต่างประเทศ ≥1M อย่างน้อย 2 คลิปคนละช่อง) แล้วเปิดห้องทำคลิปแยก 1 ห้องต่อ 1 คลิป พร้อม brief
2. ห้องทำคลิป: ค้นข้อมูล → เขียนบท (ภาษาพูดวัยรุ่นไทย) → อัดเสียงพากย์ → หาภาพ → ตัดต่อด้วยโค้ด (HTML → MP4) ใช้แม่แบบ `brainrot-v2` (ตัดเร็ว ซับใหญ่) → ผู้ตรวจอีก agent ตรวจข้อเท็จจริง/ลิขสิทธิ์/เสียง → ส่ง MP4
3. เจ้าของอัปโหลดเอง แล้วส่งภาพ Analytics กลับมา → ห้องวางแผนจดผลที่ 48 ชม.
4. งานการ์ตูน/แอนิเมชันหนัก เรนเดอร์บนการ์ดจอเครื่องเจ้าของ (RTX 3070) เร็วกว่าคลาวด์ ~17 เท่า (การ์ตูน 4 นาที ใช้ 8 นาที)

## 6. แนวทางแก้ที่กำลังทำ (เจ้าของอนุมัติแล้ว)
**ระบบตัดต่อใหม่ "v3"** (กำลังพัฒนา → ห้องตรวจอิสระ → รวมเข้าระบบหลัก):
1. **เฟรมแรก:** คำถามบนจอ + ภาพที่ทำให้แปลกใจ เข้าใจได้ใน 1 วิแม้ปิดเสียง พูดหัวข้อจบใน 1.5 วิ ห้ามปูพื้น
2. **ลูป:** ประโยคสุดท้ายต่อเข้าประโยคแรก ภาพสุดท้ายต่อภาพแรก (ให้คนดูวนซ้ำ)
3. **โครง:** เฉลยที่ ~50-60% ของคลิป แล้วมีหักมุม/ข้อแถม + 1 ข้อที่คนอยากส่งต่อเพื่อน; แนวตำนานเล่าเรื่อง 70 / หักมุม 30
4. **จังหวะ:** ตัดเร็วเฉพาะ hook กับหักมุม ช่วงอธิบายค้างภาพ 2-3 วิ; ซับ 1-3 คำต่อจังหวะ ไฮไลต์คำสำคัญ
5. **เลิกหน้าตาเดียว:** แต่ละตอนเลือก โทนสี/ฟอนต์/แบบเปิด/เพลง/เสียงพากย์/แบบปก ใหม่ และมีเครื่องมือเตือนถ้าซ้ำ 3 ตอนล่าสุด; ห้ามข้อความปกซ้ำ
6. **ความยาว:** ค่าเริ่มต้น 20-40 วิ (เพดาน 59)
7. **จังหวะลง:** วันละ 1-2 คลิป เว้นระยะ
8. พักกฎภาคต่อ → ทำหัวข้อใหม่แนวเดียวกันแทน

**แผนคลิปถัดไป:** หัวข้อร่างกายใหม่ที่ทุกคนเจอ 20-35 วิ ด้วยระบบ v3 — "ทำไมท้องร้อง" (Shorts ไทยมี 110K) สำรอง: เหน็บชา, มองแดดแล้วจาม
**วิธีวัดว่าแก้ถูก:** เทียบ "ดูต่อ vs ปัดทิ้ง" ของคลิป v3 กับคลิปเดิม (46-58%) เป้า ≥70%; ดูวิวที่ 48 ชม.

## 7. งานอื่นที่ค้าง
- การ์ตูน "ไอ้ขี้แพ้เป็นมวย" ตอน 1 (นักมวยไทยในตำนานตื่นในร่างเด็กโดนแกล้ง) เรนเดอร์เสร็จแล้ว: ยาว 4:05 + Short 52 วิ รอเจ้าของฟังเสียงก่อนอัป
- การ์ตูนอวกาศ "เคาะสามที" 5 นาที: บท + เสียงพากย์เสร็จ ยังไม่ผลิตภาพ (รอตัดสิน: ความคล้ายหนัง Project Hail Mary)
- คลิปฟุตบอล (เมสซี่ vs โรนัลโด้): ยังไม่ตัดสินว่าลงช่องไหน
- ไอเดียตำนานที่ผ่านเกณฑ์: แม่ซื้อ (660K), ผีปอบ (2.4M — ระวังประเด็นคนถูกกล่าวหาจริง)

## 8. คำถามที่อยากได้ความเห็นเพิ่ม
1. นอกจาก hook/ความยาว/หน้าตาซ้ำ มีสาเหตุอื่นที่ทำให้ "ดูต่อ" ตกจาก 75% เหลือ ~50% ไหม และทดสอบแยกอย่างไร (เปลี่ยนทีละตัวแปร)
2. บั้งไฟพญานาคได้ฟีดแค่ 4 วิวใน 26 ชม. ทั้งที่ไม่มีป้ายจำกัด — สาเหตุที่เป็นไปได้และวิธีเช็ก (ข้อห้าม: ห้ามลบแล้วอัปใหม่)
3. ทำอย่างไรให้คนคอมเมนต์ (ตอนนี้ ~0) และกลับมาดูซ้ำ (ผู้ชมใหม่ 99%)
4. ช่องไร้หน้าคน + เสียง AI จะทำให้ "ไม่ใช่แม่แบบเดียว" ในสายตา YouTube ได้อย่างไร เพื่อให้หารายได้ได้ในอนาคต
