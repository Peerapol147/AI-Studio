## Motion ที่เพิ่ม (ตามคำสั่งผู้กำกับ: ช็อตที่ footage ไม่ครบ)
- **pill เดียว morph**: ความเชื่อ (แดง ?) → ความจริง ✅ (เขียว, spring เปลี่ยนสี/กว้าง) → สัตวแพทย์ (ฟ้า +) → สมมติฐาน (เหลืองส้ม ?)
- **ป้ายชื่อเดียว morph**: เสือปลา → (slide-in) เตอร์กิชแวน → บรรพบุรุษแมวบ้าน → ลอยไปกลางจอขยายเป็น "ถิ่นแห้งแล้ง"
- **วงกลมแผนที่เดียว**: แผนที่ไทยมีจุดกะพริบ (ไม่ระบุจังหวัด) ซ้ายล่าง → ย้ายขวาบนใน fishing2 → ออก → กลับมาเป็นแผนที่ตะวันออกกลาง/แอฟริกาเหนือ (ancestor) → ขยายกลางจอบนพื้นดินแตกระแหง ซูมเข้าก้อนสีร้อนกะพริบ + ดวงอาทิตย์หมุน + heat shimmer
- fishing2: ผิวน้ำ 2 ชั้นคลื่นไหลขึ้นจากล่างการ์ด + ปลา flat ว่ายผ่าน กระโดดโค้ง + น้ำกระเซ็นตรง "ดำน้ำ" + punch-in การ์ด
- van: ป้ายชื่อ slide-in + ไอคอนหยดน้ำเด้งข้างป้ายที่ "ขึ้นชื่อ"; van2: ระลอกน้ำวนต่อเนื่องที่สายน้ำก๊อก + กระเซ็นที่ "เล่นน้ำ"
- vet: หยดน้ำไหลจากขนชื้นวนต่อเนื่อง; guess: "?" 3 อันลอยขึ้นข้างลูกแมว; swim: ระลอกน้ำ + กระเซ็นที่ "ว่ายน้ำได้" + ซูมเข้าหน้าที่ "แค่ไม่อยากเปียก"
- fur (กราฟิก): เงาแมวเดียว รับหยดน้ำ น้ำในตัวสูงขึ้น ขนลู่ → ตรง "หนัก" ตัวแมวยุบ/ฐานชั่งยุบ เข็มเกจเด้ง → ตรง "แห้งช้า" หน้าปัดเดิม morph เป็นนาฬิกา (เข็มหมุนช้า) น้ำหยดช้าๆ เป็นแอ่ง → "ไม่สบายตัว" ตัวสั่น + เส้นหนาว
- ทุกการ์ด: การ์ดลอย/หมุน ±1-2° + ภาพข้างใน push-in 8-13% + พื้นเบลอ parallax สวนทาง; ทรานซิชัน whip / zoom-through / match
