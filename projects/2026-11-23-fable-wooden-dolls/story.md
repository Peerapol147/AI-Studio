# ตุ๊กตาไม้ (นิทานเปรียบเปรย การ์ตูน AI)

ผู้ใช้อนุมัติเนื้อเรื่องนี้ 2026-11-23 ("ลุย") และสั่งส่งให้ห้อง STUDIO ANIME 2d ทำ

## Brief
- แนวคิด: การจัดลำดับความสำคัญ การออม และการใช้ทรัพยากรให้คุ้ม ถ้าไม่วางแผน ชีวิตจะไม่พัฒนาและลำบาก
- รูปแบบ: short 9:16 (1080x1920) ประมาณ 55 วิ, การ์ตูน 2D เรียบง่าย ไม่ต้องดีเทลเยอะ
- เล่าด้วยภาพล้วน ไม่มีเสียงพากย์ ไม่มีบทพูด มีข้อความบนจอภาษาไทยไม่กี่จุด + เพลงเศร้าเบาๆ + เสียงไฟปะทุ ลม หิมะ
- โทน: ป่าหิมะกลางคืน สีน้ำเงินดำ แสงส้มจากกองไฟเป็นสีอุ่นสีเดียวในภาพ
- ฉากตาย: ภาพค่อยๆ มืดลง ไม่เห็นศพ
- ช่องที่จะลง: ยังไม่กำหนด (ไม่ใช่ช่อง knowledge/football แบบเดิม)
- วิธีที่เสนอไว้ (ห้องอนิเมะตัดสินตามเครื่องมือที่มี): ช็อต action เป็นวิดีโอ ช็อตบรรยากาศเป็นภาพนิ่ง + motion; ตัวละครต้องหน้าตาเหมือนกันทุกช็อต (ทำ character sheet ก่อน)

## ตัวละครและของในเรื่อง (ต้องคงที่ทุกช็อต)
- นักเดินทาง: ตัวเล็ก ผ้าคลุมมีฮู้ดสีน้ำตาล ผ้าพันคอสีแดง (จุดจำ) หน้ากลม ตาเป็นจุด
- เลื่อนไม้: ลากด้วยเชือก ตอนแรกว่าง แล้วค่อยๆ เต็มไปด้วยตุ๊กตา
- ตุ๊กตาไม้: ตัวเล็กเท่าฝ่ามือ ถักจากกิ่งไม้ ลายเนื้อไม้วนสีทอง (ลายเดียวกับ "ไม้ท่อนสวย")
- ไม้ฟืนธรรมดา: สีน้ำตาลเทา ไม่มีลาย
- แสงหมู่บ้าน: จุดไฟสีอุ่นเล็กๆ ที่ปลายป่าไกลๆ

## กฎของโลก (ทุกฉากต้องไม่ขัด)
| กฎ | ความหมาย |
|---|---|
| หน้าหนาว ไม่มีไฟ = ตาย | ค่าใช้จ่ายจำเป็น |
| คืนละ 3 ท่อน กลางวันเก็บได้ 4-5 ท่อน | เหลือ 1-2 ท่อน/วัน = เงินเก็บ |
| ยิ่งลึกเข้าป่า ยิ่งหนาว ไม้ยิ่งหายาก | ภาระเพิ่ม รายได้ลด |
| เป้าหมาย: แสงหมู่บ้านปลายป่า | การพัฒนาชีวิต อนาคต |
| ตุ๊กตาทั้งหมดอยู่บนเลื่อน ยิ่งมากยิ่งหนัก เดินยิ่งช้า | ของสะสมถ่วงชีวิตไม่ให้ไปข้างหน้า |

## เหตุผลของเรื่อง (ห้ามตัดจุดเหล่านี้)
- ไม้ที่ "เหลือ" คือของสำรองสำหรับวันพายุ วันพายุมาจริง (S07) = เหตุกับผลชัด
- รอดครั้งแรกเพราะโชค (S09) = เหตุที่ไม่เข็ด
- ตุ๊กตาคือเพื่อนแก้เหงา (S06) = เหตุที่ไม่ยอมเผา และคนดูเห็นใจ ไม่มองว่าโง่
- เลื่อนหนักจนไปไม่ถึงหมู่บ้านที่อยู่ใกล้นิดเดียว (S11, S14) = "ชีวิตไม่พัฒนา"
- ตายไม่ใช่เพราะไม่มีทรัพยากร แต่เพราะใช้ผิดที่ (S14)
