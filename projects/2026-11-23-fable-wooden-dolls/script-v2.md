# ตุ๊กตาไม้ บท v2 (ให้เด็กก็เข้าใจ)

ผู้ใช้สั่ง 2026-11-23: v1 "แปลก เร็วมาก สื่อไม่เข้าใจ" → "แก้บทให้แม้แต่เด็กยังเข้าใจ"
พากย์อังกฤษ (ตามที่ผู้ใช้สั่ง) ยาว ~90 วิ (Shorts ได้ถึง 3 นาที) ภาพค้างฉากละ 8-14 วิ

## v1 เข้าใจยากเพราะอะไร
| ปัญหาใน v1 | แก้ใน v2 |
|---|---|
| 15 ฉากใน 55 วิ ฉากละ ~3.5 วิ ตามไม่ทัน | 9 จังหวะใน ~90 วิ จังหวะละ 1 เรื่อง |
| ไม่เคยบอกตัวเลข "เก็บ 5 ใช้ 3 เหลือ 2" คนดูต้องคิดเอง | ตัวนับไม้บนจอตลอดเรื่อง + พากย์พูดตัวเลขตรงๆ |
| ไม่บอกว่าตุ๊กตาทำจากไม้ที่ควรเก็บ | **ตุ๊กตา 1 ตัว = ไม้เหลือ 2 ท่อน** (พูดและโชว์บนจอ) |
| พากย์เป็นปริศนา ("Two to spare", "Luck saved him") | ประโยคสั้น คำง่าย มี "so / because" บอกเหตุและผลทุกครั้ง |
| ตอนจบให้คนดูตีความเอง | โชว์เลข **30 ตุ๊กตา = 60 ท่อน = พอไปถึงหมู่บ้าน** แล้วสรุปข้อคิด 1 บรรทัด |

## ตัวนับบนจอ (มุมบน อยู่ทุกฉากตั้งแต่จังหวะ 3)
`🪵 เก็บไว้: N` (ไม้สำรอง) และ `🪆 ตุ๊กตา: N` ตัวเลขเด้งเมื่อเปลี่ยน เลข "เก็บไว้" เป็น 0 ตลอดเรื่อง (เพราะไม้เหลือกลายเป็นตุ๊กตาหมด)
ข้อความบนจอใช้ภาษาอังกฤษตามพากย์ ตัวใหญ่ คำน้อย

## เช็กกับ "เหตุผลของเรื่อง" ใน story.md (ห้ามตัด)
- [x] ไม้ที่เหลือ = ของสำรองสำหรับวันพายุ → จังหวะ 3 บอกเลข, จังหวะ 5 พูดว่า "had saved none"
- [x] รอดครั้งแรกเพราะโชค เลยไม่เข็ด → จังหวะ 5 "Lucky! So he thought, 'I'll be fine.'"

## ที่เปลี่ยนจาก story.md (รอผู้ใช้อนุมัติก่อนผลิต)
- ความยาว 55 → ~93 วิ
- เพิ่มกฎ "ตุ๊กตา 1 ตัว = ไม้ 2 ท่อน" (เดิมใช้ไม้ท่อนสวย 1 ท่อน) เพื่อให้เลขตอนจบลงตัว ไม้ท่อนสวยลายทองยังอยู่ เป็นเหตุให้เขาเริ่มทำตุ๊กตาตัวแรก
- ตัดกฎ "ยิ่งลึกยิ่งหนาว ไม้ยิ่งหายาก" ออกจากเรื่อง (เด็กต้องจำหลายกฎเกินไป)
- เพิ่มข้อคิดปิดท้ายบนจอ "Save first. Fun after."
