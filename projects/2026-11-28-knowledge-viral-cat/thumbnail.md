# ปก A/B (yt-thumbnail-brief) — ข้อความจริงอยู่ใน look.json covers
สไตล์ปกเก่าที่ผู้ใช้ชอบ (never-colonized ปก A): ภาพจริงจัง + คำเด่นในกล่องเอียง + ป้ายมุม + ลูกศร/วงวาดมือ; ห้ามคลิปอาร์ต
- **A (หลัก)** ภาพ: แมวสองสีดำ-ขาวจริง (Pixabay, ภาพประกอบ) หน้าชัด + วงวาดมือรอบหย่อมขาว + ลูกศร; ข้อความ "ลายแบบนี้ / *ทาสี*มาจริงเหรอ?" ป้าย "ไวรัล"
  เหตุผล: curiosity ตรงคำถามในคลิป (เฉลย: ลายแบบนี้เกิดเองได้) ไม่หลอก
- **B** ภาพ: หน้าสมุดข่อยตำราแมว (PD British Library) ครอปแมว + วงวาดมือ; ข้อความ "แมวในตำราอยุธยา / *ยังมีอยู่*จริงไหม?" ป้าย "รู้ไหม?"
  เหตุผล: เฉลยในคลิป (วิเชียรมาศ สีสวาด ขาวมณี ยังเห็นได้) ไม่ฟันธงแมวพีพี
