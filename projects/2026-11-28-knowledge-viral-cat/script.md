# บท: แมวพีพีไวรัล ทาสีไหม? แมววิลาศจริงไหม? (ไทย, ~36 วิ)

มุม: ความเชื่อ (ทาสี / แมววิลาศโบราณ) → ความจริง (ตำราแมว 17 ชนิด, ยีน KIT ทำหย่อมขาว) → หักมุม (ตำราดูหน้าตา ไม่ใช่สายเลือด, ยังไม่มีใครยืนยัน) → ข้อส่งต่อ (5 พันธุ์อัตลักษณ์ชาติ) → คำถาม
ยอดวิว: สื่อไม่ตรงกัน (เนื้อข่าว >4 ล้าน / พาดหัว 6 ล้าน) → พูด "หลายล้านครั้ง" เท่านั้น (research.md ท้ายไฟล์)

## บทล็อก รอบ 2 (ส่ง TTS ทั้งบทเทคเดียว)
แมวบนเกาะพีพีตัวเดียว ทำชาวเน็ตเถียงกันสนั่น ว่าโดนทาสีมาหรือเปล่า
แต่คนไทยหลายคนกลับบอกว่า นี่มันแมววิลาศ ในตำราแมวโบราณนี่นา
ตำราแมวไทยมีแมวมงคลอยู่สิบเจ็ดชนิด แล้ววิลาศก็คือแมวตัวดำ ที่มีขาวแซมตามหู หาง แล้วก็ขา
แต่ลายแบบนี้ไม่ต้องทาสีก็เกิดเองได้นะ เพราะยีนบางตัวทำให้เซลล์สีไปไม่ถึงบางจุดของผิว ขนตรงนั้นเลยออกมาเป็นสีขาว
ส่วนจะเป็นแมวโบราณจริงไหม อันนี้ยังตอบไม่ได้ เพราะตำราดูแค่สีขนกับหน้าตา ไม่ได้ตรวจสายเลือด
แมวในตำราที่ยังเห็นได้ทุกวันนี้ ก็อย่างวิเชียรมาศ สีสวาด แล้วก็ขาวมณี
แมวที่บ้านลายตรงตำราไหม เมนต์บอกหน่อย

| "บางคนว่าลายแปลกขนาดนี้ต้องแต่งสีแน่ๆ" (ซ้ำกับ hook "ทาสี") | ฟองคอมเมนต์ใน hook_fight |
| "...ที่ไทยเพิ่งประกาศให้เป็นอัตลักษณ์ของชาติไปเมื่อปีที่แล้ว" | ตราบนจอ "5 พันธุ์ อัตลักษณ์ชาติ · ครม. พ.ย. 2568" (ช็อต share_law) |
