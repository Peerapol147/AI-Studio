# Hand rig (มือ SVG ข้อนิ้วหมุนได้) สำหรับซีรีส์ "ลองทำตามเดี๋ยวนี้"

ผู้ใช้ 2026-11-25 (ตอน palmaris-test, feedback ข้อ 6): "การวาดแบบนี้ค่อยเข้าท่าหน่อย"
**ผ่าน:** มือ SVG rig นี้ | **ไม่ผ่าน (ห้ามใช้):** มือการ์ตูนขาวแบน ("Motion มันห่วยแตก"), มือ 3D หุ่นนิ่ง + เส้นชี้ ("มีแต่เส้นแปลกๆ"), ปกมือคลิปอาร์ต ("ปก AI")
ที่มา: `projects/2026-11-25-knowledge-palmaris-test/video/episode/hand.js` (branch `claude/ep-2026-11-25-palmaris-test`) คัดลอกมาไม่แก้

## คืออะไร
มือขวาด้านฝ่ามือ (นิ้วชี้ขึ้น นิ้วโป้งอยู่ซ้ายของคนดู ข้อมือ + แขนลงขอบล่าง) จากโครงกระดูก 3D เล็กๆ:
นิ้วละ 3 ข้อหมุนที่ข้อจริง (MCP/PIP/DIP), นิ้วโป้งใช้ IK ให้ปลายนิ้วไปแตะนิ้วก้อย, ข้อมืองอได้, perspective, เงา/แสงทรงกระบอกต่อข้อนิ้ว,
ลายมือ, เส้นเอ็น palmaris บนแขน + วงไฮไลต์ สีผิวผสมจาก palette ของ look (`hand-rig.css`) จึงเปลี่ยนตาม look.json
`draw(state)` เป็นฟังก์ชันบริสุทธิ์ (state เดียวกัน = ภาพเดียวกัน) จึง seek ได้ใน HyperFrames (ห้ามสุ่ม/ห้ามเก็บสถานะข้ามเฟรม)

## ใช้
```html
<link rel="stylesheet" href="compositions/components/hand-rig/hand-rig.css"/>
<svg id="hand" viewBox="0 0 1080 1920"></svg>
<script src="compositions/components/hand-rig/hand.js"></script>
<script>
const R = window.HandRig(document.getElementById('hand'));   // สร้างครั้งเดียว
// ทุกเฟรม (ใน update ของ timeline): คำนวณ state จากเวลา t แล้ววาด
const r = R.draw({ o: 1, op: 1, flex: 40, tendon: 1, X: 540, Y: 1250, S: 1.2, yaw: -4, pitch: 4, roll: 6 });
// r.wrist, r.tendon, r.thumbTip, r.pinkyTip, r.touch = จุดบนจอ (px) ไว้วางป้าย/ลูกศร/วงให้ติดมือ
</script>
```
ดูตัวอย่างท่า: เปิด `demo.html?pose=rest|test|flex`; ตัวอย่างใช้งานจริงทั้งตอน (กล้องต่อช็อต, ท่าตามเวลา, ป้ายติดนิ้ว) ดู `video/episode/episode.js` ของตอน palmaris

| state | ความหมาย | ช่วง |
|---|---|---|
| `o` | นิ้วโป้งพับข้ามฝ่ามือไปหานิ้วก้อย | 0-1 |
| `op` | นิ้วก้อยพับมาหานิ้วโป้ง | 0-1 |
| `press` | ดันปลายนิ้วโป้งกดนิ้วก้อย (px) | 0-20 |
| `spread` | กางนิ้ว | 0-1 |
| `wig` | ขยับนิ้วชี้/กลาง/นาง/ก้อยแยก (องศา) | `[a,b,c,d]` |
| `flex` | งอข้อมือเข้าหาตัว (องศา) | 0-60 |
| `tendon` | เส้นเอ็นนูน + ไฮไลต์บนแขน | 0-1 |
| `pulse`, `ring` | แสงเรือง / วงไฮไลต์ที่จุดแตะ | 0-1 |
| `X`, `Y`, `S` | ตำแหน่งข้อมือบนจอ (px) และสเกล (กล้อง) | |
| `yaw`, `pitch`, `roll` | หมุนกล้องรอบมือ (องศา) | ±25 |

## กติกา
- ท่าต้องถูกกายวิภาคตามบท (เช็กกับ research.md) และดู contact sheet ทุก 0.25 วิ (`tools/contact_sheet.py`) ว่าข้อนิ้วไม่หักผิดทาง/ไม่ทะลุกัน
- กล้องขยับทุกช็อต (ค่า X/Y/S/yaw/roll เปลี่ยนตามเวลา) ห้ามมือค้างนิ่ง >0.5 วิ
- ป้าย/ลูกศรวางจากจุดที่ `draw()` คืนมา (ติดมือ) ไม่ใช่เส้นชี้ลอยจากขอบจอ
- ตอนนี้มีแค่มือขวาด้านฝ่ามือ: ท่าหลังมือ/มือซ้าย/สองมือ ยังไม่รองรับ ถ้าต้องใช้ ขยาย `hand.js` แล้วจดลงตารางนี้ (`transform="scale(-1,1)"` กลับเป็นมือซ้ายได้แบบง่าย)
- ใช้ในปกได้ (`templates/brainrot-v3/cover.html` วาดใน `#art`) ตามตัวอย่าง `video/cover.html` ของตอน palmaris
