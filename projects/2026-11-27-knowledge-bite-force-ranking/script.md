## รอบ 2 (ตัดให้สั้น): เทคแรก 600 ตัวอักษร = 52.6 วิ (11.4 ตัว/วิ) เกินเป้า 30-45 → ตัดคำพูดเทียบที่ซ้ำ ย้ายไปไว้บนจอแทน (ไม่ตัดคำกำกับ)
| ตัด/แก้ | เหตุผล |
|---|---|
| "ห้าเท่าของคนเลย" (ไฮยีนา) | ย้ายขึ้นจอเป็นแถบเทียบ "≈5 เท่าแรงกัดผู้ชาย"; ตอนพูดคำว่า "คน" กว้างเกิน (ค่าผู้หญิง 597 N = 7.5 เท่า) |
| "เท่ารถเวฟสิบคันแล้ว" (อัลลิเกเตอร์) | ย้ายขึ้นจอ (ไอคอนรถ 10 คัน) |
| "ผู้ชายที่กัดสุดแรง" → "แรงกัดผู้ชาย" | สั้นลง ความหมายเท่าเดิม (ค่าเทียบ = ผู้ชาย ฟันกราม) |
| "ได้จากโมเดลในคอมพิวเตอร์นะ" → "มาจากโมเดลในคอม"; "ฉลามตัวจริง" → "ฉลามจริง"; "แชมป์ก็คือ" → "แชมป์คือ"; "วัดกันจริงๆ" → "วัดจริง" | "คอม" คนพูดจริง; คำ "ไม่ได้วัด"/"วัดจริง" ยังอยู่ |
| "เดาไว้ก่อนเลยว่าอันดับหนึ่ง" → "เดาไว้ก่อนเลย ที่หนึ่ง"; ตัด "ไว้หน่อย" ท้าย cta; ไฮยีนา ตัด "กัดแรง" | สั้นลง ไม่เสียความหมาย |
