## เช็กลิสต์ "เหมือนคนพูด" (เกลาก่อนล็อก)
1. คำภาษาเขียน: ไม่มี "พวกเขา / และ / ซึ่ง / โดย / ทำให้เกิด" ✅ (ร่างแรก "ส่งผลให้" → ไม่ใช้)
2. คำขึ้นความเชื่อ: "เคยโดนทักป่ะ ว่า..." (ไม่ซ้ำ "ผู้ใหญ่ชอบขู่ว่า" ของหักนิ้ว และไม่ใช้ "หลายคนเชื่อว่า") ✅
3. คำลงท้าย: ป่ะ (2), นะ (5), เลย (6), หน่อย (7) = 4 คำใน 7 ประโยค ไม่ยัดทุกประโยค ✅
4. จังหวะหยุดก่อนเฉลย: "เข่าดังกร๊อบ..." (ฉาก 1), "จริงๆ แล้ว..." (ฉาก 3) ✅
5. ไม่มี "คุณ": ฉาก 7 ใช้ "เข่าใคร" แทน "เข่าคุณ" (หักนิ้วใช้ "คุณ") ✅
ทดสอบ "ผู้ชาย 28 พูดกับเพื่อน":
- ฉาก 2 ร่างแรก "หลายคนเชื่อว่าเสียงในเข่าเกิดจากน้ำไขข้อลดลง" ✗ ภาษาเขียน → "เคยโดนทักป่ะ ว่าเข่าดังเพราะน้ำในข้อแห้ง" ✓ (คนไทยพูด "น้ำในข้อแห้ง/หมด" จริง)
- ฉาก 3 ร่างแรก "ความจริงคือ crepitus พบได้ในคนที่ไม่มีอาการ" ✗ ศัพท์ → "เข่าดังเจอได้บ่อยมาก แม้แต่คนที่ไม่เจ็บเข่า" ✓
- ฉาก 5 ร่างแรก "อย่างไรก็ตาม มีงานวิจัยพบว่าความเสี่ยงสูงขึ้น" ✗ → "แต่ก็มีงานวิจัยเจอว่า ... เสี่ยงเข่าเสื่อมมากกว่านะ" ✓
- ฉาก 6 ✓ พูดเป็นกฎง่ายๆ แบบบอกเพื่อน
- ฉาก 7 ร่างแรก "แล้วคุณล่ะ เข่าดังไหม? คอมเมนต์บอกเรา" ✗ "คุณ" + ทางการ → "แล้วเข่าใครดังบ้าง? เมนต์บอกหน่อย" ✓
