## Hook 3 แบบ (เทสต์ปิดเสียง 1 วิ: รู้ไหมว่าเรื่องอะไร + อยากรู้คำตอบไหม)
| | ข้อความบนจอ = คำพูด | ปิดเสียง 1 วิ |
|---|---|---|
| A | เรื่องแม่นาคที่ทุกคนรู้... อาจไม่ใช่ฉบับแรกนะ | รู้ว่าแม่นาค แต่ "ฉบับแรก" ลอย ไม่มีอะไรให้อยากรู้เจาะจง |
| **B (เลือก)** | **ผัวแม่นาค ในฉบับเก่าสุด... ไม่ได้ชื่อมากนะ** | รู้ทันทีว่าแม่นาค + ข้อมูลขัดสิ่งที่ทุกคนรู้ ("พี่มาก") → อยากรู้ว่าชื่ออะไร (เฉลยที่ ~38 วิ ดึงให้ดูช่วงเล่าเรื่องจนจบ) ✅ |
| C | ถ้าแม่นาคไม่ใช่ผี... แล้วใครหลอกคนทั้งคลอง? | แรง แต่อิงข้อ ⚠️ (อุบายลูกชาย) เป็น hook = หนักแน่นเกินป้าย ตัดทิ้ง |

## โครง (70/30)
1. Hook 0-3 วิ (B)
2. เล่าเรื่อง ~0:03-0:36 (ตำนาน ❌ ขึ้นด้วย "เล่ากันว่า") ภาษาพูดแบบเพื่อนเล่าเรื่องผี มี "..." ก่อนจุดหลอน; [whispers] 1 จุดตอนเริ่มเล่า
3. หักมุม ~0:36-0:53: ฉบับเขียนเก่าสุดที่เจอ (✅) → ผัวชื่อชุ่ม (✅) → ชื่อมากมาทีหลัง (⚠️ "ว่ากันว่า") → อุบายลูกชาย (⚠️ "บางตำรา") → ฉากมะนาวยังหาต้นทางไม่เจอ (✅ ตามที่ค้นจริง)
4. ปิด ≤4 วิ: "แล้วที่เคยได้ยินมา ผัวแม่นาคชื่ออะไร เมนต์บอกหน่อย" → วนกลับ hook (ภาพคลองเดียวกับเฟรมแรก)
