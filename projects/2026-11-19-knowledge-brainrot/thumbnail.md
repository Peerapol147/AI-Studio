# ปก (skill yt-thumbnail-brief) — Shorts: คนเห็นเฟรม 0 ใน feed มากกว่าปก (ฟีด Shorts 95% ของวิวช่อง) ปกจึงต้องหน้าตาเดียวกับเฟรม 0
ชื่อคลิปพูดเรื่อง "Brainrot + จริงไหม" แล้ว → ปกทำหน้าที่ภาพ: นิ้วเลื่อนฟีดตอนดึก + สมองการ์ตูนที่วาดเอง
ข้อยกเว้นจาก skill: skill ห้ามข้อความปกซ้ำชื่อคลิป แต่ style.md ช่องนี้กำหนดให้เฟรม 0 = ปก = คำถาม hook (ช่องอยู่ได้ด้วย feed) → ใช้กฎช่อง แต่ย่อให้ ≤4 คำ

## A (แนะนำ) — ตรงกับเฟรม 0
- ภาพเด่น: มือ/นิ้วเลื่อนมือถือในห้องมืด แสงจอส่องมือ (เฟรมจากช็อต hook ที่ผู้กำกับเลือก) จุดสนใจ Y 500-1300
- กราฟิก: สมองการ์ตูนสีชมพูที่วาดเอง "ละลาย" นิดๆ ลอยออกจากจอมือถือ (ตัวเดียว ไม่ใช่ตัวละครมีมของคนอื่น)
- ข้อความ: **สมองเน่าจริงไหม** (3 คำ ไม่มีเครื่องหมาย) Kanit 900 ขาวขอบดำ + คำว่า "Brainrot" ป้ายเล็กสีเหลืองด้านบน, ทั้งหมดใน Y 240-700
- สี/คอนทราสต์: พื้นน้ำเงินเข้ม-ม่วงกลางคืน vs แสงจอขาวฟ้า vs สมองชมพู = 3 โทนแยกกันชัด
- เทส 120 px: ต้องอ่าน "สมองเน่า" ได้และเห็นมือถือเรืองแสง (สมองเป็นรอง)
- ห้าม: ข้อความใน Y 0-240 / 1440-1920, ขวาล่าง X>900 ใต้ Y 840, โลโก้แอป

## B — ไม่มีมือ ใช้สมองเป็นจุดเด่นเดียว
- สมองการ์ตูนตัวใหญ่กลางจอ ครึ่งซ้ายละลาย ครึ่งขวาปกติ (สื่อ "ความเชื่อ vs ความจริง") ข้อความเดียวกับ A
- เสี่ยง: ไม่บอกทันทีว่าเกี่ยวกับมือถือ/ฟีด

## C — ข้อความล้วน
- พื้นมืด + "Brainrot" ตัวยักษ์มีเอฟเฟกต์ glitch + "จริงไหม" ตัวรอง
- เสี่ยง: ไม่มีจุดภาพ ผ่านเทส 120 px แต่ดึงอารมณ์น้อย
