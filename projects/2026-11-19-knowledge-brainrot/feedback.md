# Feedback ผู้ใช้ตอน brainrot (2026-11-19): บทของผู้ใช้ชนะ, ตัดต่อของดราฟต์ก่อนแก้ชนะ

**จำง่ายๆ: บท = แบบผู้ใช้ (v3) | ตัดต่อ = แบบดราฟต์ก่อนแก้ (v2)**

## บท: v2 (ทีม) vs v3 (ผู้ใช้) — ผู้ใช้ชอบ v3
| ฉาก | v2 ทีม (แปลก) | v3 ผู้ใช้ (ดี) | ทำไม v3 ดีกว่า |
|---|---|---|---|
| hook | Brainrot ทำสมองพังจริงไหม? | Brainrot ทำให้สมองพัง? จริงหรอ? | ถามสองจังหวะแบบคนพูดจริง |
| อธิบายคำ | (ไม่มี) เลื่อนถึงตีสอง แล้วบ่นว่าสมองเน่า | Brainrot แปลว่าสมองเน่า ผู้คนมักจะใช้แซวตัวเองเวลาไถคลิป แนว short หรือ tiktok ทั้งคืน | อธิบายศัพท์ทันที + ยกตัวอย่างที่เห็นภาพ |
| Oxford | Oxford ยกให้เป็นคำแห่งปี 2024 | มันฮิตซะจน Oxford เลือกเป็นคำแห่งปี 2024 | มีประธาน + คำเชื่อมเหตุผล |
| หักมุม | แต่นิยามยังเขียนว่า ความเสื่อมที่ "คนคิดว่า" เกิด | (ตัดทิ้ง) | มุกภาษาศาสตร์ต้องอธิบายยาว คนไม่เข้าใจ |
| หลักฐาน | ยังไม่มีหลักฐานว่าคลิปสั้นทำสมองเน่าถาวร | แต่ยังไม่มีหลักฐานว่า คลิปสั้นทำให้สมองเน่าจริงนะ | น้ำเสียงคุย มี "แต่...นะ" |
| งานวิจัย | คนดูหนักๆ มักทำเทสสมาธิได้แย่กว่า | งานวิจัยแค่เจอว่า คนที่ไถคลิปหนักๆ มักทำการทดสอบเกี่ยวกับสมาธิได้แย่กว่าคนที่ไม่ค่อยมีพฤติกรรมนี้ | บอกว่าใครเจอ เทียบกับใคร ครบ |
| สัมพันธ์ | แต่แค่สัมพันธ์กัน อาจเพราะเครียดเลยเลื่อนหนัก | หรืออาจเป็นเพราะเครียดอยู่แล้ว เลยทำให้ไถหน้าจอหนักกว่าเดิมก็ได้ | ไม่ใช้ศัพท์ "สัมพันธ์" ในเสียง ให้ตัวอย่างแทน |
| ทริก | ทริก: อย่าเลื่อนบนเตียง คนเล่นมือถือก่อนนอน มักนอนน้อยลง | ทริกง่ายๆนะ อย่าไถบนเตียงก่อนนอน ... มักนอนน้อยลงและหลับยาก | "ไถ" ไม่ใช่ "เลื่อน"; คำพูดจริง |
| ปิด | คืนนี้เลื่อนถึงกี่โมง? ก่อนสงสัยอีกรอบว่า | คืนนี้จะไถถึงกี่โมง? เมนต์บอกหน่อย อย่าลืมพักผ่อน | ไม่มีประโยคค้าง + ใส่ใจคนดู |
ต้นเหตุ v2 แปลก: ผู้กำกับตัดบท 470→340 ตัวอักษรเพื่อให้ ≤30 วิ จนคำเชื่อม/ประธานหาย + ยัดมุก "supposed"
ผู้กำกับเกลาได้เฉพาะข้อเท็จจริง และคำที่เกลาต้องเป็นคำไทยที่พูดจริง ("หลับไม่ค่อยดี" ผู้ใช้บอกคนไทยไม่ใช้ → คง "หลับยาก")

## ตัดต่อ: v2 (ดราฟต์ก่อนแก้) vs v3 (final) — ผู้ใช้ชอบ v2
| | v2 ดราฟต์ (ชอบ) | v3 final |
|---|---|---|
| ความยาว | 26.3 วิ | 35.3 วิ |
| ช็อตเฉลี่ย | 1.38 วิ (19 ช็อต) | 1.53 วิ (23 ช็อต) |
| loop | เสียงพากย์พาวน (ประโยคท้ายต่อเข้า hook) + ภาพวน | วนด้วยภาพอย่างเดียว |
→ เป้าตัดต่อ: ช็อตเฉลี่ย ~1.4 วิ, คลิปกระชับ, loop ที่เสียงพาวนกลับ

## ข้อขัดกันที่ต้องแก้ในตอนหน้า
บทแบบผู้ใช้ยาวกว่า (≈500 ตัวอักษร ≈35 วิ) แต่ตัดต่อที่ชอบมาจากคลิป 26 วิ
→ อย่าตัดคำเชื่อมเพื่อให้สั้น ให้ **เลือกประเด็นน้อยลง** (เช่น 1 ความเชื่อ + 1 หลักฐาน + 1 ทริก) เขียนแบบผู้ใช้ แล้วตัดภาพที่ ~1.4 วิ
→ ประโยคปิดที่พาวนกลับต้องเป็นประโยคเต็มที่ฟังรู้เรื่อง (เช่น จบด้วยคำถามที่ตรงกับ hook) ไม่ใช่ประโยคค้าง
