## ยอดวิว (ห้องวางแผน)
- ต่างประเทศ: "What If The Earth Stopped Rotating? 🤔" 46M; แนว what-if อวกาศ: "What If The Earth Was Flat?" 31M, "What would happen if Earth fell into a black hole?" 4.8M (≥2 คลิปคนละช่อง ผ่านเกณฑ์ ≥1M)
- ไทย: "ถ้าโลกหยุดหมุน" แค่ 1.3K = ช่องว่าง ยังไม่มีใครทำดี
- ไม่ซ้ำตอนเก่า (solar-storm, space-toilet, space-fart คนละเรื่อง)
- เหตุผลผู้ใช้: หัวข้อที่ต้องใช้ฟุตเทจเหตุการณ์จริงเฉพาะตัวทำยาก → เรื่องนี้เล่าด้วยกราฟิก + ภาพ NASA (สาธารณสมบัติ) + ฟุตเทจทั่วไป (เมือง ทะเล ลม ท้องฟ้า)

## มุมเล่า
what-if เป็นลำดับเวลา: วินาทีแรก → ชั่วโมงแรก → วันต่อมา → เดือนต่อมา แล้วหักมุม: โลกหมุนช้าลงจริงทีละนิด แต่ไม่มีทางหยุดกะทันหัน = ไม่ต้องกลัว (ไม่ขู่เกินจริง)
- ตัวเลขตั้งต้น: เส้นศูนย์สูตร ~1,670 กม./ชม., ไทย (ละติจูด ~14°) ~1,600 กม./ชม. (คำนวณ+ยืนยัน)
- ผลถัดมา: ทุกอย่างที่ไม่ยึดพื้นพุ่งไปทางตะวันออก, ลม, มหาสมุทรไหลไปขั้วโลก, กลางวัน/กลางคืนอย่างละ ~6 เดือน, สนามแม่เหล็ก — เฉพาะที่แหล่งรองรับ; ส่วนคาดการณ์ใช้ "นักวิทยาศาสตร์คาดว่า"
- ปิด: คำถามตอบสั้น "ถ้าเลือกได้ อยากอยู่ฝั่งกลางวันหรือกลางคืน?"
- คนดู: คนทั่วไปที่ชอบ what-if อวกาศ

## สไตล์ (เรียนรูปแบบจาก Shorts what-if อเมริกา ห้ามลอกภาพ/บท/ชื่อ)
1. ชื่อ = คำถาม what-if สั้น + อีโมจิ 1 ตัว ("ถ้าโลกหยุดหมุน? 🌍")
2. เฟรม 0 = โลกกำลังหมุน + ข้อความคำถาม → "หยุด" ตรงคำพูด (แรงกระแทก/สิ่งของพุ่ง) กราฟิก HyperFrames + ภาพโลก NASA
3. ป้ายเวลาบนจอ morph ต่อเนื่อง (วินาทีแรก → ชั่วโมงแรก → วันต่อมา → เดือนต่อมา), SFX ตรงแอ็กชัน, ลูปเนียน
4. ตัวเลขทุกตัวบนจอหยุดบนค่าที่มีแหล่ง
