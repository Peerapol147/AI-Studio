# Storyboard: ถ้าโลกหยุดหมุนกะทันหัน (v3, look: night-violet / prompt / pop / question / tilt / zoom)
ภาพละเอียดต่อช็อต: `shots.json` (`desc`) — เวลามาจาก words.json ผ่าน `tools/shot_times.py` เท่านั้น

## ป้ายเวลาบนจอ (morph ต่อเนื่อง ชิ้นเดียว มุมบนซ้าย Y 240-330)
"ตอนนี้" (setup) → "วินาทีแรก" (ช็อต stop, ตอนพูด "พอพื้นหยุดปุ๊บ") → "ต่อมา" (ช็อต daynight) → "ทั้งปี" (ช็อต sixmonth/orbit) → หายตอน twist ("ไม่ต้องกลัว" = ป้ายกลายเป็น ✓ "ของจริง")
แคปซูลเดียวกัน spring เปลี่ยนความกว้าง/ข้อความ ไม่โผล่ใหม่
