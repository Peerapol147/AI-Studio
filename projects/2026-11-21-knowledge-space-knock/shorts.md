# Shorts 3 ตัว (9:16 1080x1920, ≤59 วิ) ตัดจาก "เคาะสามที"

ทำหลังคลิปยาวเสร็จ ใช้เสียงพากย์ชุดเดียวกัน (**ไม่อัดเสียงเพิ่ม** ยกเว้น hook ใหม่ของแต่ละตัวที่ระบุตัวอักษรไว้) ภาพครอปกลางจากฉาก 16:9 (ตัวละครอยู่กลาง 1/3 ตาม storyboard) ช็อตไกลที่ครอปแล้วเสียความหมาย (1.7, 5.11, 8.6, 9.9) ให้จัดเฟรมแนวตั้งใหม่
ลำดับลง: S1 ก่อนหรือพร้อมคลิปยาว (ไม่สปอยล์) → S2 หลังคลิปยาว 1-2 วัน → S3 หลังคลิปยาว ≥3 วัน (สปอยล์หักมุม)
ทุกตัวจบด้วยการ์ดเล็ก 1.5 วิ "ดูเต็มเรื่อง ▶ เคาะสามที" + ลิงก์คลิปยาวในคอมเมนต์ปักหมุด/ฟีเจอร์ related video
hook ตามสูตร Y10 (skill `yt-hook-scripter`): ความระทึกอยู่บนเฟรมแรก + ตัวหนังสือบนจอ (ดูแบบปิดเสียงได้) + ตอนจบวนกลับเฟรมแรก

---

## S1 "ใครเคาะ" — ท่อน 1 (+ช็อต 4.9-4.12) · ~42 วิ · ไม่สปอยล์
**0-3 วิ (เฟรมแรก):** ช็อต 1.9 มือต้นแนบผนัง นิ้วเด้งตามเสียงเคาะ 3 ครั้ง ตัวหนังสือบนจอบนสุด: **"ข้างนอกยานคือสุญญากาศ… แล้วใครเคาะ"**
- เสียง: ก๊อก ก๊อก ก๊อก (ไม่มีพากย์ใน 3 วิแรก = ใช้เสียงเคาะเป็น hook)
**ลำดับ:** 1.9 → 1.1 → 1.3-1.4 ("ปลาทู เปิดฮีตเตอร์… ลืม ปิดแกไปแล้ว") → 1.7 ("ยานลำนี้มีคนอยู่คนเดียว…") → 1.8 → 4.11 (กราฟสามยอดเท่ากัน "ห่างเท่ากันเป๊ะครับ") → 4.12 ("หินมันชนเป็นจังหวะได้ด้วยเหรอวะ") → 1.10 ("ใครเคาะวะ")
**วน:** จบที่หน้าต้น "ใครเคาะวะ" แล้วตัดเงียบ 0.3 วิ → เฟรมแรกคือมือบนผนังที่เคาะต่อทันที (คนดูรู้สึกว่าเคาะซ้ำ)
**เสียงใหม่:** ไม่มี (0 ตัวอักษร)
**คำถามปักหมุด:** "ถ้าได้ยินเสียงเคาะแบบนี้กลางอวกาศ จะเคาะตอบไหม"

## S2 "มันเคาะตรงรูรั่ว" — ท่อน 6 · ~45 วิ · สปอยล์เล็กน้อย
**0-3 วิ:** ช็อต 6.2 HUD ตัวเลขอากาศวิ่งลงเร็วผิดปกติ สีเหลือง ตัวหนังสือ: **"อากาศรั่ว แต่หารูไม่เจอ"**
- พากย์ hook ใหม่ (ผู้บรรยาย): "อากาศกำลังรั่วออกจากยาน แต่เขาหารูไม่เจอ" (**41 ตัวอักษร**)
**ลำดับ:** 6.2 → 6.3 (เหงื่อเกาะหน้า) → 6.5 (ภาพตัดขวาง ขอบแผ่นใสเคาะตรงรู — คนดูเห็นก่อนต้น) → 6.6 → 6.7-6.8 ("มือโดนดูดเลย… เจอแล้ว!") → 6.9-6.10 ("ขอโทษนะแม่" ปะด้วยซองบะหมี่) → 6.11 → 6.17 ("บังเอิญ หรือเปล่าวะ")
**วน:** จบที่ต้นหันมองหน้าต่าง → เฟรมแรก HUD วิ่งลงอีกครั้ง
**คำถามปักหมุด:** "บังเอิญ หรือมีอะไรช่วยเขาอยู่"
**ข้อเท็จจริงที่แทรกได้ (ตัวหนังสือเล็ก):** "ในที่ไร้น้ำหนัก เหงื่อไม่หยด มันเกาะตัว" (research 6.2 ⚠️ พูดแค่ "เกาะ")

## S3 "เคาะตอบ" — ท่อน 7 ช็อต 7.14-7.16 + ท่อน 8 · ~48 วิ · สปอยล์หักมุม (ลงหลังสุด)
**0-3 วิ:** ช็อต 8.2 ต้นเคาะผนัง 3 ที ตัวหนังสือ: **"เขาเคาะตอบ…"** → 8.3 เงียบ (หน้าต้นหูชิดผนัง)
- เสียง: ก๊อก ก๊อก ก๊อก (ต้นเคาะ) แล้วเงียบ (0 ตัวอักษร)
**ลำดับ:** 8.2 → 8.3 → 8.4 (ผนังเคาะตอบ) → 8.5 (แสงส้มเข้าห้อง) → 8.6 (เผยตัวเต็ม ค้าง 4 วิ — ทำเฟรมแนวตั้งใหม่: โซ่แผ่นหกเหลี่ยมพาดแนวตั้งจากบนลงล่าง ยานเล็กตรงกลาง) (เสียงผู้บรรยาย "หลุมขั้วดวงจันทร์… เย็นต่ำกว่าลบสองร้อยองศา" ทับช็อตนี้) → 8.7 (ขอบแผ่นดูดเกล็ดน้ำแข็ง) → 8.10-8.11 ("แกพาฉันไปเจอรูรั่วเหรอวะ… หรือแกแค่หิววะ") → 8.12 (กะพริบ 3 ที)
**วน:** แสงกะพริบครั้งที่ 3 ตัดเข้าเฟรมแรก (ต้นเคาะ) = จังหวะ 3-3 ต่อกัน
**เสียงใหม่:** ไม่มี
**คำถามปักหมุด:** "มันช่วย หรือมันแค่หิว"
