# ปก (Shorts feed เห็นเฟรมแรกมากกว่าปก → ปก = เฟรม 0 เวอร์ชันนิ่ง) — skill yt-thumbnail-brief
- ภาพเด่น (1 จุด): ลูกไฟแดงอมชมพูเรืองพุ่งจากแม่น้ำโขงยามค่ำ แสงสะท้อนบนน้ำ + เงาพญานาคจางๆ ใต้น้ำ
- ข้อความ ≤4 คำ: **"ลูกไฟนี้ ใครจุด?"** ("ใครจุด?" สีเหลือง) ไม่ซ้ำชื่อคลิป (ชื่อคลิปพูดถึง บั้งไฟพญานาค/ความจริง)
- อ่านออกที่ 120 px: ข้อความ ≥12% ความกว้าง ขาวขอบดำหนา ลูกไฟ contrast สูงกับพื้นน้ำเงินเข้ม
- ทางเลือก A/B: (2) ครึ่งบนเงาพญานาค / ครึ่งล่างเส้นกระสุนส่องแสง ข้อความ "พญานาค หรือ คน?"
- ห้าม: ภาพจากทีวี/ข่าว/หนัง โลโก้
