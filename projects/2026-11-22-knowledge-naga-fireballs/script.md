# บท: บั้งไฟพญานาค (ไทย, เป้า 35-50 วิ, สูงสุด 59) — บทพากย์ล็อกใน `vo-th.txt` (ส่ง ElevenLabs ตรงตามไฟล์นั้น)

## Hook 3 แบบ (skill yt-hook-scripter, Shorts 3-Second Hook; เทสต์ปิดเสียง 1 วิ: รู้ไหมว่าเรื่องอะไร + อยากรู้คำตอบไหม)
| | ข้อความบนจอ = คำพูด | ปิดเสียง 1 วิ |
|---|---|---|
| **A (เลือก)** | **ลูกไฟนี้... ใครเป็นคนจุด?** (จอ: "ลูกไฟนี้ใครจุด?") | เห็นลูกไฟแดงพุ่งจากแม่น้ำกลางคืน + คำถามสั้น 4 คำ อ่านทันใน 1 วิ คนไทยส่วนใหญ่รู้ทันทีว่าบั้งไฟพญานาค และคำว่า "ใคร" เปิดสองฝ่าย (พญานาค vs คน) ✅ ตรงกับคำถามปิดท้าย = loop |
| B | ไม่มีเสียง ไม่มีควัน... แล้วลูกไฟนี้มาจากไหน? | ยาวเกินอ่านใน 1 วิ และ "ไม่มีเสียงไม่มีควัน" เป็นข้อ ⚠️ (คำบอกเล่า) ไม่ควรขึ้นจอเป็นประโยคหลัก |
| C | ทีวีเคยถ่ายเจอ... ว่าลูกไฟนี้คือกระสุน? | แรง แต่เปิดด้วยฝั่ง "มีคนทำ" = ดูเหมือนฟันธง ผิดโทนเคารพความเชื่อ และข้ามช่วงเล่าเรื่อง (บทเรียนผีอำ) ตัดทิ้ง |

Loop: ประโยคสุดท้าย "พญานาค หรือ มีคนทำ?" → ภาพแม่น้ำ+ลูกไฟเดียวกับเฟรม 0 → กลับเข้า "ลูกไฟนี้ ใครเป็นคนจุด?"

## โครง (~55/45 ตามความยาวตัวอักษร; ช่วงเล่าเรื่องรวม hook ~60%)
1. Hook 0-3 วิ (A)
2. เล่าตำนาน ~3-28 วิ: คืนออกพรรษา ริมโขงหนองคาย (✅) → ลูกไฟแดงอมชมพูผุดจากน้ำ (เล่ากันว่า) → บางปีเป็นร้อยๆ ลูก (✅ ปี 2564 กว่า 600 ลูก กรมประชาสัมพันธ์) → ไม่มีเสียง ไม่มีควัน (เล่ากันว่า) → ชาวบ้านเชื่อว่าพญานาคจุดถวายพระพุทธเจ้าเสด็จกลับจากดาวดึงส์ (✅ ว่ามีคนเชื่อ) → "ไม่เชื่อก็อย่าลบหลู่นะ"
3. หักมุม ~28-44 วิ: หมอเสนอก๊าซ (✅ มีคนเสนอ / ⚠️ ตัวสมมติฐาน) → รายการทีวีปี 2545 ถ่ายเจอทหารลาวยิงกระสุนส่องแสง (✅ รายการออกอากาศแบบนั้น) → คนในพื้นที่ไม่พอใจ ขู่ฟ้อง (✅) → ยังไม่มีคำตอบไหนที่ทุกฝ่ายยอมรับ (✅)
4. ปิด ≤4 วิ: "แล้วคิดว่าไง พญานาค หรือ มีคนทำ? เมนต์บอกหน่อย"

พอฟ้ามืด... จะมีลูกไฟสีแดงอมชมพู ผุดขึ้นมาจากใต้น้ำ
บางปีนับได้เป็นร้อยๆ ลูกเลยนะ

คืนนั้นพญานาคจะจุดลูกไฟ ถวายพระพุทธเจ้า ตอนเสด็จกลับจากสวรรค์ชั้นดาวดึงส์

## เกลาแล้ว (เช็กลิสต์ทุกบรรทัด)
- ไม่มี "พวกเขา/และ/ซึ่ง/โดย/คุณ" (เช็กด้วยสคริปต์แล้ว)
- คำลงท้ายพูดจริง: "เลยนะ", "เฉยๆ", "นะ", "เลย", "หน่อย", "คนนึง" — ผู้ชาย 28 เล่าเรื่องให้เพื่อนฟังริมโขง ✓
- ตัวเลข/ปี: พูด "เมื่อยี่สิบกว่าปีก่อน" (2545→2569 = 24 ปี) แทนเลขปี; จอใส่ "พ.ศ. 2545"; "เป็นร้อยๆ ลูก" แทน 600 (จอ "ปี 2564 นับได้กว่า 600 ลูก")
- โทน: ไม่ฟันธง ไม่ล้อ ไม่เรียกความเชื่อว่าผิด; ฝั่ง "มีคนทำ" ใช้กริยา "บอกว่า/ไปถ่ายเจอ" ไม่ใช่ "พิสูจน์แล้ว"
- ห้ามพูด: ชื่อสถานี/รายการ (ไม่จำเป็น และเลี่ยงกล่าวหาสื่อ), ชื่อหมอ, จำนวนคนดู, ขนาด/ความสูงลูกไฟ, "พิสูจน์แล้ว"
- จุดอ่านยาก (ให้ voice/reviewer ฟัง): "ดาวดึงส์", "อมชมพู", "ลบหลู่", "ก๊าซ"
- ~603 ตัวอักษร (ไม่นับวรรค/แท็ก) ≈ 46-50 วิ ที่ 12-13 ตัว/วิ; โควตา ElevenLabs ที่ใช้ ≈ 660 ตัว
