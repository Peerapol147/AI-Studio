## Motion graphic ที่ทำเอง
ลูกไฟ (halo 2 ชั้น + body + core ขาวชมพู + ประกาย 7 จุด, เงาสะท้อน, ระลอก, หยดน้ำ) ใช้ตัวเดียวกันทุกฉาก; เงาพญานาค procedural (spine คลื่นเดินทาง + หัวมีหงอน + เกล็ดสะท้อนแสงไล่, ลำแสงใต้น้ำ, ผิวน้ำ);
แผนที่โขงเส้นเรือง; ฟองก๊าซ; ทีวีเก่า (static canvas PRNG ต่อเฟรม); แผนภาพ 2 ฝั่ง + เส้นกระสุน (หัวเป็นลูกไฟเล็ก = เหตุที่คนสับสน); เงาฝูงคน; การ์ด 3 ใบ + "?" + วงเช็กว่าง

## ใช้จาก hyperframes-registry
- `grain-overlay` → grain ทั้งเฟรม (ทำให้ seek ได้: tile PNG seed คงที่ เลื่อนตามเฟรม แทน CSS animation)
- `rgb-glitch-text` (มากับแม่แบบ) → "ขู่ฟ้อง!" สีแดง + RGB split 5 เฟรม; `camera-shake` เป็นแบบของการสั่นกล้องตอน ขู่ฟ้อง (ลบไฟล์ออก ใช้สูตร closed-form)
- `flash-through-white` เป็น shader 1920x1080 ไม่เข้ากับคอมโพสิชันเดียว → แฟลช t1 ทำเป็น div ขาว 2 เฟรม + จางถึง 0.2 วิ
- ค้น glow/particles/water/map แล้วไม่มีชิ้นที่เป็นลูกไฟ/แม่น้ำแนวตั้ง → ทำเอง
