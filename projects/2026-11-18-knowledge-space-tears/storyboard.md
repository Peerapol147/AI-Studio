# Storyboard (9:16, ~23 วิ) — ภาพทั้งหมดตัดจาก NASA "Moving Water in Space" (ISS, public domain) ช่วงเวลาต่างกัน ครอปกลางเฟรมเลี่ยงตัวหนัง NASA ด้านขวา
เวลาจริงมาจาก `assets/audio/shots-th.json` เท่านั้น (ดู shots.json: cue = คำที่ตัดเข้า)
| ช็อต | cue | ภาพ | motion |
|---|---|---|---|
| hook | ร้องไห้ | นักบิน + ก้อนน้ำลอยตรงหน้า | ซับ/หัวเรื่องคำถามบนจอตั้งแต่ 0.0 วิ, push-in ช้า |
| cheek | แก้ม | ก้อนน้ำใกล้ใบหน้า | ลูกศรชี้แก้ม + เครื่องหมาย ? |
| belief | หลายคน | นักบินมองกล้อง | ป้าย "คนส่วนใหญ่คิดว่า: ไหลลงแก้ม" |
| truth | ความจริง | มือถือแท่งน้ำ | ป้ายเปลี่ยนเป็น ✗ ไม่ไหล (hit: ไม่ไหลเลย) |
| float | ทุกอย่างลอย | ก้อนน้ำลอยข้างแท่ง | pan ช้า |
| nopull | ไม่มีอะไรดึง | ก้อนน้ำลอยนิ่ง | ลูกศรแรงโน้มถ่วงขีดฆ่า (รูปร่างเดียว morph) |
| merge | รวมตัว | นักบินเป่า/ปั้นก้อนน้ำ | zoom เข้า |

| stick | เกาะอยู่ | ก้อนน้ำเกาะแท่ง | ป้ายชี้ "เกาะอยู่ที่ตา (อธิบายด้วยภาพก้อนน้ำ)" |
| bigger | ยิ่งใหญ่ | ก้อนใหญ่ใกล้หน้า | scale ขึ้น |
| wipe | เช็ดออก | มือเข้าเฟรม | - |
| earth | ไหลลงมา | ภาพก้อนน้ำ | ไอคอนหยดไหลลงบน "บนโลก" |
| nofall | ไม่ตก | ก้อนน้ำลอยค้าง | หยดค้างกลางจอ |
| tissue | ผ้าเช็ดหน้า | ภาพมือ | ไอคอนผ้าเช็ดหน้า |
