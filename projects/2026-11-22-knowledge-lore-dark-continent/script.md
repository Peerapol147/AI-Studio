## Hook 3 แบบ (ทดสอบปิดเสียง 1 วิ)
| | คำพูด = ข้อความบนจอ | เฟรม 0 | ปิดเสียง 1 วิ |
|---|---|---|---|
| **A ✔ เลือก** | "ทุกที่ที่กอนเคยไปมา เป็นแค่จุดเล็กๆ กลางทะเลสาบยักษ์" | แผนที่กราฟิก: จุดเรืองแสงเล็กๆ + วงกลมแดง + ลูกศร "โลกที่รู้จัก" กลางทะเลสาบดำมืด | รู้ว่าเรื่อง HxH/แผนที่ + อยากรู้ว่ารอบๆ คืออะไร |
| B | "ไปพันคน รอดกลับมาเจ็ด" | ตัวนับ 1000 → 7 | ช็อกแต่ไม่รู้ว่าเรื่องอะไร |
| C | "มดคิเมร่าที่ว่าโหด ยังได้แค่เกรด B" | ป้ายเกรด B | แรงสำหรับแฟน แต่คนนอกไม่เข้าใจ |
เลือก A: ตรงมุม "แผนที่" ที่ต่างจากคลิปที่มีอยู่ และคนไม่ใช่แฟนก็เข้าใจภาพ

## บทพากย์ (จุดดึงทุก 5-7 วิ)
1. (0-5) hook: ทุกที่ที่กอนเคยไปมา เป็นแค่จุดเล็กๆ กลางทะเลสาบยักษ์ชื่อโมเบียสนะ
2. (5-11) ซูมออก: ที่ล้อมรอบอยู่คือทวีปมืด ใหญ่จนเน็ตโรที่เคยไปกับซิกก์ โซลดิ๊ก ยังบอกว่ามันใหญ่เกินไปแล้ว
3. (11-16) ตัวเลข: คนพยายามข้ามไปร้อยสี่สิบเก้าครั้ง มีแค่ห้าครั้งที่มีคนรอดกลับมา
4. (16-20) หักมุม: ห้าครั้งนั้นไปเอาของวิเศษ [whispers] แต่ที่ติดกลับมาจริงๆ คือภัยพิบัติ
5. (20-26) การ์ด 1: ไปเอาหินปั่นไฟ เจอปาปุ ตัวที่เลี้ยงคนเป็นสัตว์เลี้ยง ไปพันคน รอดเจ็ด
6. (26-31) การ์ด 2: ไปเอาสมุนไพรรักษาทุกโรค เจอไบรออน อาวุธพืช รอดสองคน
7. (31-36) การ์ด 3: ไปเอาข้าวอายุยืน เจองูสองหางเฮลเบล โดนไปเก้าสิบเก้าเปอร์เซ็นต์
8. (36-41) การ์ด 4: ไปเอาน้ำวิเศษ เจอไอ ก๊าซที่มีชีวิต รอดสามคน แต่สติหลุดไปแล้ว
9. (41-47) การ์ด 5: ทีมสุดท้ายได้ของมาจริง แต่ของตายกลางทาง แถมพาโรคที่ทำให้คนไม่ตายกลับมาด้วย
10. (47-52) คนที่กลับมา: แล้วหนึ่งในคนที่รอด คือบียอนด์ ลูกชายเน็ตโร ที่กำลังจะกลับไปอีกรอบ
11. (52-55, ≤4 วิ) ปิด: ถ้าต้องไปเอง ของชิ้นไหนคุ้มเสี่ยงสุด เมนต์มาเลย → ภาพซูมกลับเข้าจุดเล็กๆ บนแผนที่ (= เฟรม hook) วนลูป

## ข้อความบนจอเสริม (ไม่พูด)
- ป้ายสปอยล์ 0-3 วิ (ชิปเล็กบน Y~260): "⚠ สปอยล์มังงะ เล่ม 32-34"
- แผนที่: "ไม่ใช่สเกลจริง" มุมล่างของแผนที่
- การ์ด: ชื่อไทย + อังกฤษ (Pap / Brion / Hellbell / Ai / Zobae) + เกรดจากตารางสมาคมฮันเตอร์ (A / B+ / A / A / B+) + ตัวนับผู้รอด
