## ภาษาภาพ (กราฟิกของเราเอง ≥ ครึ่งคลิป: 30/40 ช็อตเป็นกราฟิกล้วน)
- พื้น: แผนที่สไตล์ "เอกสารลับนักสำรวจ" — กระดาษดำหมึกน้ำเงินเข้ม/ทอง เส้นกริด เข็มทิศ หมอกเคลื่อน เกรนฟิล์ม
- สี: ของรางวัล = ทอง `#F5C04A`, ราคา/ภัยพิบัติ = แดง `#E5383B`, ข้อมูล = ขาว/ฟ้าอ่อน
- แผนที่เป็น **รูปร่างเดียว morph ต่อเนื่อง**: จุดเล็ก → ทะเลสาบ → ทวีปมืด → เส้นเรือ 149 → 5 หมุด → (การ์ด) → กลับมาเป็นจุดตอนจบ (ลูป)
- การ์ด 5 ภัยพิบัติ: การ์ดใบเดียวที่**พลิก** ด้านทอง "ไปเอา" → ด้านแดง "เจอ" + เกรด (ตารางสมาคมฮันเตอร์) + ตัวนับผู้รอด
- ภาพนิ่งจากผู้ใช้: ในกรอบการ์ด ≤ 70% ความกว้างจอ เอียง ±2° มี push-in 8-12%, ลูกศร/วงกลม/ข้อความวิเคราะห์ทับ, โชว์ ≤2 วิ, เครดิตเล็ก "HUNTER×HUNTER © Yoshihiro Togashi / Shueisha" ใต้การ์ด
- ป้ายสปอยล์ 0-3 วิ: ชิปเล็ก "⚠ สปอยล์มังงะ เล่ม 32-34" Y≈250 (ไม่บัง hook)
- ข้อความ hook = คำพูดคำต่อคำ: "ทุกที่ที่กอนเคยไปมา เป็นแค่จุดเล็กๆ กลางทะเลสาบยักษ์" ตั้งแต่เฟรม 0 (เฟรม 0 = แผนที่มืด + จุดเรือง + วงกลมแดง)
- Safe zone ตาม style.md (ซับ Y 1100-1300, กราฟิกหลัก Y 500-1300, ไม่มีของสำคัญ Y<240 / Y>1440, X ≤900 ใต้ Y 840)
