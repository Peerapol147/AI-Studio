# บท: "ไอ้ขี้แพ้เป็นมวย" (ไม่มีเสียงพากย์ — บอลลูน/ป้าย/เสียงเอฟเฟกต์)

ประโยคเดียว: แชมป์มวยไทยตื่นมาในร่างเด็กขี้แพ้ ทนแก๊งนักเลงเพราะ "มันยังเด็ก" จนมันผลักเพื่อนล้มแล้วเหยียบสมุดที่เด็กวาดรูปฮีโร่ไว้ ซึ่งก็คือตัวเขาเอง

## Hook 3 แบบ (yt-hook-scripter, Y10 Shorts 3-Second Hook) — ทดสอบปิดเสียง ดู 1 วิแรก
| | เฟรม 0 | ข้อความบนจอ | ปิดเสียงรู้เรื่อง? | อยากดูต่อ? |
|---|---|---|---|---|
| **A (เลือก)** | เด็กผอมผมปิดตา ยืนจดมวย แก๊ง 3 คนล้อม มุมต่ำ | "ทุกคนคิดว่ามันขี้แพ้..." | ✅ เห็นท่ามวย + โดนล้อม = จะมีสู้ | ✅ ประโยคค้าง "...แต่?" |
| B | แก๊งนอนกองพื้น เพื่อนในห้องอ้าปาก | "ไอ้ขี้แพ้ประจำห้อง ล้มนักเลงทั้งแก๊ง?" | ✅ | ⚠️ เฉลยตอนจบไปแล้ว เหลือแค่ "ยังไง" |
| C | ตาเด็กใต้ผมม้าเปลี่ยนเป็นตาดุ | "ร่างนี้ขี้แพ้ แต่ข้างในคือแชมป์มวย" | ⚠️ ภาพตาเดียวไม่บอกเรื่องโรงเรียน | ✅ |
เลือก A: ภาพบอกว่าจะมีสู้ ข้อความค้างไว้ให้อยากรู้ว่า "แต่...?" แล้วตัดย้อนทันทีที่ 2.2 วิ
**วนลูป:** ช็อตสุดท้าย (คำถาม) อยู่บนภาพเด็กยืนจดมวยท่ามกลางแก๊งที่นอนกอง = ภาพเดียวกับเฟรม 0 แต่ผลกลับด้าน วนกลับไป "ทุกคนคิดว่ามันขี้แพ้..." ได้พอดี

## ใครพูด (สีขอบบอลลูน)
- มานพในร่างกล้า: **บอลลูนความคิด (เมฆ) ขอบทอง** = เสียงในใจ / บอลลูนพูดขอบทองตอนพูดจริง
- บอส: ขอบแดง | โจ้/เต้: ขอบส้ม | ปอนด์: ขอบฟ้า | เพื่อนในห้อง: ขอบขาว
