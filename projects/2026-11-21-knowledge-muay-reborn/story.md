# เรื่องยาว: "ไอ้ขี้แพ้เป็นมวย" ตอนที่ 1 (ผู้ใช้สั่ง 2026-11-21: ปูเรื่องดีๆ ยาวได้ถึง 10 นาที)

รูปแบบ (ผู้ใช้เลือก): **คลิปยาว 16:9 1920x1080 ~7 นาที** ทำเป็นท่อน 30-60 วิ (story-craft ข้อ 8) + **Short 9:16 ≤59 วิ** ตัดจากฉากสู้ ชี้กลับคลิปยาว
เสียง (ผู้ใช้เลือก): ไม่มีพากย์ บอลลูนคำพูด + ป้าย + เสียงเอฟเฟกต์ + เพลงฟรี ข้อความอ่านทัน ~13 ตัวอักษร/วิ

## แก่นเรื่อง (series bible)
- **ประโยคเดียว:** แชมป์มวยที่เคยสอนว่า "มวยมีไว้ปกป้องคน ไม่ได้มีไว้รังแกคน" ตื่นมาในร่างเด็กขี้แพ้ที่โดนรังแก เขาทนเพราะ "มันยังเด็ก" จนวันที่มันทำร้ายคนอื่น คำสอนเดิมของเขาเองกลายเป็นเหตุผลที่ต้องสู้
- **เส้นเรื่องชิ้นเดียว:** สมุดวาดรูปของกล้า (หน้าแรก: รูปแสงชัย + "สักวันจะเก่งแบบพี่แสงชัย", หน้าท้าย: ประโยค "มวยมีไว้ปกป้องคน")
- **หักมุมเปลี่ยนความหมาย:** ท่อน 2 แสงชัยพูดประโยคนี้กับเด็กผอมคนหนึ่งที่ค่ายมวยแล้วลืมไป → ท่อน 4 เจอประโยคเดียวกันในสมุด = กล้าคือเด็กคนนั้น → ท่อน 7 ประโยคนี้คือเหตุผลที่ลุก
- **กฎโลก:** ร่างกล้าอ่อนแอ (หอบ เหนื่อยง่าย) แสงชัยมีแค่ "ฝีมือ+จังหวะ" ไม่มีแรง → ชนะด้วยแม่ไม้ ไม่ใช่กำลัง
- **ตัวละคร (สมมติทั้งหมด ออกแบบเอง):**
  | ตัว | หน้าที่ | หน้าตา |
  |---|---|---|
  | แสงชัย (52) | แชมป์มวยไทย 3 สมัย เลิกชกแล้ว เปิดค่ายเล็กๆ ที่แทบไม่มีเด็ก | ผมเทาเกรียน แผลเป็นคิ้ว หนวด ไหล่หนา |
  | กล้า (ม.4) | เจ้าของร่าง ขี้อาย ชอบวาดรูป แฟนมวยแสงชัย | ผอม ผมม้ายาวปิดตา (ตอนตื่นสู้: ปัดผมขึ้น ตาดุ) |
  | ปอนด์ | เพื่อนคนเดียวของกล้า | เตี้ย แว่นกลม ผมทรงกะลา |
  | บอส (ม.5) | หัวโจก | ตัวใหญ่ ผมตั้งแหลม ปลดกระดุมเห็นเสื้อแดงข้างใน พับแขนเสื้อ |
  | โจ้ / เต้ | ลูกน้อง | โจ้ อ้วน หัวเกรียน / เต้ ผอมสูง ผมปัดข้าง |
  | เพื่อนในห้อง | ปฏิกิริยา "ว้าว" | หมิว (ผมบ็อบ), เฟิร์น (หางม้า), นัท (หัวเกรียน) |
- **ภาพ:** p5.brush เส้นหมึก+สีน้ำ ชุดนักเรียนไทยทั่วไป ไม่มีชื่อโรงเรียน/โลโก้ ฉาก: ค่ายมวย ห้องนอน ห้องเรียน ห้องน้ำ (กระจก) ทางเดิน หลังโรงเรียน
- **ความรุนแรง:** การ์ตูน ไม่มีเลือด ไม่มีอาวุธ โดนแล้วดาวหมุน/ตากากบาท

## Short (9:16, ≤59 วิ) — ตัดจากท่อน 7-9 + hook
hook A (cold open จดมวย "ทุกคนคิดว่ามันขี้แพ้...") → เหยียบสมุด (สั้น) → "พอแล้ว." → 3 แม่ไม้ → "ทำไมไอ้ขี้แพ้เป็นมวย?!" → การ์ด "ดูเต็มเรื่องที่คลิปยาว" + คำถาม
ใช้ช็อต/โค้ดชุดเดียวกัน กล้องตั้งใหม่ (ครอปแนวตั้ง ตัวละครกลางภาพ)

## วิธีผลิต
1. ทุกท่อนเป็นไฟล์ `anime/parts/pNN.js` (รายการช็อต) ใช้ engine ชุดเดียวกัน เรนเดอร์ทีละท่อน `renders/parts/pNN.mp4`
2. ต่อท่อนด้วย ffmpeg (ตัดแข็งที่รอยต่อ) + เพลงคลอยาววางทับทีหลัง + sfx ตามคิวของแต่ละท่อน
3. คลาวด์: เรนเดอร์ทดสอบความละเอียดต่ำเฉพาะช่วงสั้น / เต็ม: เครื่องผู้ใช้ (RENDER-ON-GPU.md)
