# บท: ทำไมยิ่งเกายิ่งคัน (short ไทย 20-35 วิ)

## Hook 3 แบบ (ทุกแบบมีเดิมพัน/คำแปลก/ขัดที่เชื่อ — style.md ข้อ 1)
1. **(เลือก)** "เวลาเกาแก้คัน เรากำลังทำให้ตัวเองเจ็บนะ" — (ข) คำแปลก: เกา = ทำให้ตัวเองเจ็บ (✅ research ข้อ 2) + (ค) ขัดที่เชื่อ (คนคิดว่าเกา = แก้); หัวข้อ "เกาแก้คัน" จบใน ~1 วิ
2. "ยิ่งเกายิ่งคัน ไม่ได้คิดไปเองนะ มีงานวิจัยด้วย" — (ค) ขัดที่เชื่อ; แพ้เพราะต้องรีบใส่ "ในหนู" ใน hook ไม่งั้นอ้างเกิน
3. "คันแล้วเกา อาจทำให้คันหนักกว่าเดิม" — (ก) เดิมพันกับตัวคนดู; แพ้เพราะฟังเป็นคำขู่/คำแนะนำแพทย์ (feedback ข้อ 5 ไม่ขู่เกินจริง)
เทสต์ปิดเสียง 1 วิ: เฟรม 0 = ภาพมือเกาแขนจริง + ข้อความ hook คำต่อคำ + kicker "POV: โดนยุงกัด" → รู้ว่าเรื่องคัน/เกา และอยากรู้ "ทำไมเจ็บ?"
หมายเหตุห้องวางแผน: ไม่เปิดด้วย "ทำไม..." ลอยๆ (ตลาดไทยล้น) ✔

## บทพากย์ (ฉบับล็อก หลังขั้นเกลา)
| beat | บท | ป้าย research |
|---|---|---|
| hook | เวลาเกาแก้คัน เรากำลังทำให้ตัวเองเจ็บนะ | ✅ ข้อ 2 |
| setup | เริ่มจากตอนโดนยุงกัด เซลล์ในผิวจะปล่อยสารเคมีอย่างฮิสตามีนออกมา | ✅ ข้อ 1 |
| explain | สารนี้ไปปลุกเส้นประสาทรับความคัน แล้วสัญญาณก็วิ่งผ่านไขสันหลังขึ้นไปถึงสมอง สมองก็เลยสั่งให้เราเกา | ✅ ข้อ 1 |
| reveal | พอเกา ผิวจะเจ็บนิดๆ แล้วความเจ็บนี่แหละ ที่ไปกลบความคันไว้ชั่วคราว | ✅ ข้อ 2 (ชั่วคราว) |
| twist | แต่งานวิจัยหนึ่งในหนูเจอว่า พอเจ็บ สมองจะหลั่งเซโรโทนินออกมาระงับความเจ็บ แล้วเซโรโทนินตัวนี้แหละ ดันไปเร่งสัญญาณคันในไขสันหลังให้แรงขึ้นอีก ยิ่งเกาก็เลยยิ่งคัน | ⚠️ ข้อ 3 (คำกำกับ "งานวิจัยหนึ่งในหนู" ห้ามตัด) |
| share | แถมความคันยังติดต่อกันได้ด้วยนะ แค่เห็นคนอื่นเกา หลายคนก็คันตามแล้ว | ✅ ข้อ 4A (ในคน; "หลายคน" = คำกำกับ) |
| cta | ดูมาถึงตรงนี้ เริ่มคันตรงไหนแล้ว? เมนต์บอกหน่อย | - |

ลูป: "...เมนต์บอกหน่อย" → "เวลาเกาแก้คัน เรากำลังทำให้ตัวเองเจ็บนะ" (ประโยคจบในตัวทั้งคู่ ต่อกันลื่น: คนที่เพิ่งคันแล้วเกาพอดี)
ไม่มีคำแนะนำการรักษา (ตัดเรื่องประคบเย็นทิ้ง: ห้องวางแผนห้ามเสียงเป็นหมอ/แนะนำเกินแหล่ง)
