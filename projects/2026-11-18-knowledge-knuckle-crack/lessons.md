# บทเรียนตอน knuckle-crack (ข้อเสนอแก้ไฟล์ร่วม ยังไม่ได้แก้เอง)
1. make-clip ขั้น 1 (หัวข้อจากเทรนด์): ผู้ใช้อนุญาต youtube.com แล้ว (www./m.) อ่านยอดวิวได้ด้วย curl หน้า `/results?search_query=...&sp=EgIYAQ%253D%253D` แล้ว grep `accessibilityText` (ไม่ดาวน์โหลดคลิป) researcher ไม่มี Bash ผู้กำกับต้องรันเอง → ใส่ใน SKILL.md ขั้น 1
2. scribe_v1 ถอด "กร๊อบ" เป็น "ก๊อบ" ทำให้หา cue ไม่เจอ → เพิ่มในตาราง "ปัญหาที่เจอแล้ว": คำควบกล้ำ ร/ล ให้ใช้คำข้างเคียงเป็น cue และแก้ซับกลับเป็นคำสะกดถูก
3. shot_times เตือนว่าช็อตสั้นเกิน (<0.6 วิ) เมื่อคำ cue อยู่ติดกัน → ร่าง cue ให้ห่างกันอย่างน้อย ~5-6 คำไทย / 3 คำอังกฤษ
4. หัวข้อเรื่องร่างกาย/อาการ: Pixabay ไม่มีวิดีโอเลย ได้แต่ภาพนิ่ง ≤1280px → ในขั้น 1 ให้เช็ก totalHits ของ *videos* สำหรับ action หลักก่อน ถ้าไม่มีให้วางแผนเป็นกราฟิกตั้งแต่ตอนเขียนบท
5. แม่แบบ motion (wrinkly-fingers) อยู่คนละ branch → ใช้ `git archive origin/<branch> <path> | tar -x` ได้ ควรเขียนไว้ใน SKILL หรือ merge แม่แบบเข้า branch หลัก
6. storyboard ควรระบุเพศ/ลักษณะคนในภาพให้ตรงบท (บท EN พูด "his" แต่ภาพหมอเป็นผู้หญิง) และตัวนับในกราฟิกห้ามหยุดบนตัวเลขที่ไม่มีแหล่ง (มี "×5,685" ขึ้นแวบหนึ่ง) → ใส่ในเช็กลิสต์ style.md
7. `.claude/skills/sound-effects/scripts/__pycache__` ถูก track ใน git และถูกแก้ทุกครั้งที่มิกซ์ → ลบออกจาก repo และใส่ .gitignore
8. `.env` ไม่ติดไปเซสชันใหม่ → ตั้ง PIXABAY_API_KEY ใน Environment variables
