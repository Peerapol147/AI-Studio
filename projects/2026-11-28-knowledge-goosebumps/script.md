# บท: ทำไมเราขนลุก (แม้แต่ตอนฟังเพลง) 🥶 (short ไทย ~33-37 วิ)

## Hook 3 แบบ (ทุกแบบต้องมีเดิมพัน/คำแปลก/ขัดที่เชื่อ — style.md ข้อ 1)
1. **(เลือก)** "ทุกครั้งที่ขนลุก ร่างกายเรากำลังพยายามพองขน ให้ตัวดูใหญ่เหมือนแมวเลยนะ" — (ข) คำแปลก/ภาพแปลก: คน = แมวพองขน ต้องฟังต่อถึงจะเข้าใจ + (ก) เป็นเรื่องในร่างกายคนดูเอง; หัวข้อ "ขนลุก" อยู่ในคำแรกๆ (<1 วิ); จริงตาม research ข้อ 2.1 + 2.3 (รีเฟล็กซ์เดียวกับที่ทำให้สัตว์ขนพองดูตัวใหญ่ ในคนแทบไม่ได้ผล — คำว่า "พยายาม" สื่อตรงนี้)
2. "ขนลุกตอนฟังเพลง แปลว่าสมองกำลังหลั่งโดพามีนอยู่" — (ข)+(ก); แพ้: งานวัดความสัมพันธ์ (research 4.1 ห้ามพูดเป็นเหตุ-ผลเด็ดขาด) + เอาข้อแถมท้ายมาเปิด ช่วงกลางจะไม่มีอะไรดึง
3. "ขนลุกที่ใครๆ ว่าไร้ประโยชน์ อาจช่วยให้ขนงอกใหม่" — (ค) ขัดที่เชื่อ; แพ้: ต้องรีบใส่ "ในหนู" ใน hook ไม่งั้นอ้างเกิน และเฟรม 0 ภาพผิวคนจะชวนเข้าใจผิดว่าเป็นในคน
เทสต์ปิดเสียง 1 วิ: เฟรม 0 = ภาพ close-up ผิวแขนขนลุกจริง + ข้อความ hook + kicker "POV: ขนลุกซู่" → รู้ว่าเรื่องขนลุก และอยากรู้ "เกี่ยวอะไรกับแมว?"
เทสต์คนไม่รู้เรื่อง: ตอบแค่ "มี/ไม่มี" ไม่ได้ ต้องถามต่อ "พองขนยังไง?" ✔

## บทพากย์ (ฉบับล็อก หลังขั้นเกลา) — `script-vo-th.txt`
| beat | บท | ป้าย research |
|---|---|---|
| hook | ทุกครั้งที่ขนลุก ร่างกายเรากำลังพยายามพองขน ให้ตัวดูใหญ่เหมือนแมวเลยนะ | ✅ 2.1 (สัตว์ขนพองดูตัวใหญ่) + ⚠️ 2.3 (ในคนเป็นรีเฟล็กซ์ตกทอด — บอกในประโยค reveal) |
| explain | เพราะที่โคนขนทุกเส้นมีกล้ามเนื้อจิ๋วเกาะอยู่ พอเราหนาวหรือตกใจ มันก็หดตัว ดึงขนให้ตั้งขึ้นมา | ✅ 1.1, 1.2 |
| reveal | แต่คนเราขนน้อยเกินไป มันเลยแทบไม่ได้ผล นักวิทยาศาสตร์มองว่าเป็นร่องรอยจากบรรพบุรุษ | ✅/⚠️ 2.3 (คำกำกับ "นักวิทยาศาสตร์มองว่า" ห้ามตัด) |
| twist | แต่มันอาจไม่ได้ไร้ประโยชน์ซะทีเดียวนะ ทีมฮาร์วาร์ดเจอว่าในหนู ระบบนี้ช่วยปลุกรากขนให้งอกขนใหม่ตอนหนาว | ✅ 3.1-3.2 (คำกำกับ "อาจ", "ในหนู" ห้ามตัด; ไม่พูด "2 สัปดาห์") |
| share | ส่วนขนลุกตอนฟังเพลง งานวิจัยเจอว่าสมองหลั่งโดพามีน สารที่เกี่ยวกับความรู้สึกดีๆ | ✅ 4.1 ("งานวิจัยเจอว่า" = พบร่วมกัน ไม่ได้บอกว่าโดพามีนทำให้ขนลุก) |
| cta | เพลงไหนทำให้ขนลุก พิมพ์มาหน่อย | - |

ลูป: "...พิมพ์มาหน่อย" → "ทุกครั้งที่ขนลุก ร่างกายเรากำลังพยายามพองขน..." (ทั้งคู่จบในตัว ต่อกันลื่น: คนที่เพิ่งนึกถึงเพลงที่ทำให้ขนลุก ได้ยินประโยคแรกต่อพอดี) ภาพ: ช็อต loop เล่นภาพผิวขนลุก (plate hook) จบที่เฟรม 0
จุดดึงทุก 5-7 วิ: 0 วิ แมว (ภาพแปลก) → ~4 วิ ซูมทะลุผิว → ~7 วิ ขนเด้ง "ปึ๊บ" → ~11 วิ หักว่า "แทบไม่ได้ผล" → ~15 วิ ลิง/บรรพบุรุษ → ~18 วิ หักมุม "แต่..." + หนูทดลอง → ~23 วิ รากขนงอก → ~27 วิ เพลง + สมองเรืองแสง → ~32 วิ cta
ไม่มีคำแนะนำการแพทย์ ไม่มีภาพโรคผิวหนัง; ไม่มีตัวเลข % บนจอ (research 4.2); ตัด "ไม่ใช่ทุกคนเป็น" ออกเพื่อให้ความยาวไม่เกิน ~37 วิ (ตัดทั้งประเด็น ไม่ตัดคำเชื่อม)
