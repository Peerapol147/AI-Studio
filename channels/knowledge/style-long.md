# คู่มือสไตล์คลิปยาว (16:9) — เรียนจากคลิปตัวอย่างที่ผู้ใช้ส่ง (2026-11-28)

ที่มา: ผู้ใช้ส่งไฟล์ "20 วินาทีแห่งหายนะ ความโลภที่คร่า 502 ชีวิต" (ช่องเล่าคดี/ภัยพิบัติแบบมีพิธีกร, เรื่องห้างซัมพุงถล่ม เกาหลีใต้ 1995)
ผู้ใช้สั่ง: "เรียนรู้การทำคลิปยาวแนวนี้ ... จนกว่าจะได้สไตล์การตัดต่อ การทำภาพ จังหวะ ใส่เสียง การพูด และฟุตเทจ รวมถึงวิธีการสร้างมันขึ้นมา"
**เรียนแค่รูปแบบ ไม่ลอกเนื้อหา ภาพ บท หรือหน้าตาช่องเขา** (ช่องนี้ใช้ภาพข่าว/สารคดีทีวีที่ติดลิขสิทธิ์ ซึ่งช่องเราห้ามใช้ — ดูข้อ "ปรับใช้กับช่องเรา")

## 2. โครงเรื่อง (ถอดจากบทจริง นาทีต่อนาที)
| นาที | ช่วง | เทคนิค |
|---|---|---|
| 0:00-1:00 | **Cold open แบบละคร** เล่าเหตุการณ์วันเกิดเหตุเป็นปัจจุบันกาล ผ่านมุมลูกค้า (ร้อนผิดปกติ → รอยร้าว → น้ำหยด → ปูนร่วง → ถามพนักงาน → ตึกสั่น) จบด้วย "อีกไม่กี่นาทีต่อจากนั้นคือความหายนะที่ไม่มีใครคาดคิด" + เสียงดนตรีกระแทก | เปิดลูปใหญ่ทันที ไม่บอกชื่อสถานที่จนจบ cold open; ภาพตัดถี่ 1-3 วิ |
| 1:00-3:00 | ปูฉาก: ที่ไหน (กังนัม) ใหญ่แค่ไหน (4 หมื่นคน/วัน) ดังแค่ไหน (สื่อต่างประเทศทำสารคดี) | ตัวเลขยืนยันความสำคัญ "ทำไมต้องฟัง" |
| 3:00-6:00 | ตัวละครหลัก (ประธาน/เจ้าของ) ปูมหลัง วิธีรวย | สร้าง "ตัวร้าย" ให้คนดูอิน |
| 6:00-17:00 | **ห่วงโซ่การตัดสินใจผิด** เรียงเป็น "ปัญหาที่หนึ่ง ... ปัญหาที่สอง ..." (ตัดเสา, ย้ายบันไดเลื่อน, เปลี่ยนชั้น 5 เป็นร้านอาหาร, พื้นหนาขึ้น, แอร์ 45 ตันบนหลังคา, ย้ายแอร์) | ไต่ระดับทีละข้อ แต่ละข้อมีแผนภาพ/ภาพประกอบ; ผู้พูดแทรกอารมณ์ ("หมั่นไส้", "มึงทำอะไรของมึง") |
| 17:20-18:30 | สปอนเซอร์ (อ่านโฆษณาเอง + โลโก้ซ้อน) | วางตรงกลางก่อนไคลแมกซ์ คนดูติดแล้ว |
| 19:00-23:30 | สัญญาณเตือนวันเกิดเหตุ: รอยร้าวขยาย → ประชุมบอร์ด → ไม่อพยพ → ถล่ม "เหมือนแพนเค้ก ชั้นห้า สี่ สาม สอง หนึ่ง" | ปิดลูปจาก cold open (กลับมาจุดเดิมแต่ตอนนี้คนดูรู้สาเหตุ) |
| 24:00-31:30 | กู้ภัย + เรื่องเล่าผู้รอดชีวิต (คนสุดท้ายรอด 17 วัน) | ช่วงอารมณ์/มนุษย์ |
| 32:00-37:30 | สอบสวน ผลคดี ตัวเลขผู้เสียชีวิต/บาดเจ็บ ผลกระทบต่อกฎหมายก่อสร้าง | ปิดด้วยตัวเลขชัด |
| 38:00-39:35 | ชะตากรรมตัวละคร + บทเรียน + ปิดท้ายชวนคอมเมนต์/ติดตาม | จบเร็ว ไม่ลากยาว |
หลักโครง: **cold open ปลายเปิด → ย้อนเล่าตั้งแต่ต้น → ห่วงโซ่เหตุ (นับข้อ) → กลับมาวันเกิดเหตุ → ผลลัพธ์มนุษย์ → บทสรุป**

## 3. การพูด
- ภาษาพูดเต็มที่แบบเล่าให้เพื่อนฟัง: "เนี่ย", "นะครับ", "อ่ะ", คำสบถเล็กน้อย, เรียกคนดู "ทุกท่าน"
- **บทพูดแทนตัวละคร** (re-enact): "เฮ้ย ทำไมวันนี้มันร้อนจังเลย", "คุณเอาเทปปิดไว้ เดี๋ยวลูกค้าจะกลัว" — ทำให้เป็นฉาก ไม่ใช่การอ่านข้อมูล (⚠️ ช่องเรา: ถ้าใช้ต้องบอกว่าเป็นการจำลอง/ตามคำบอกเล่าในแหล่ง ห้ามแต่งคำพูดบุคคลจริงเป็นข้อเท็จจริง)
- คำถามชวนคิดทุก 1-2 นาที ("ถามว่าเฮ้ยอีจุนเก่งมากเหรอ ทำไม...?") = จุดดึงใหม่
- อุปมาภาพชัด ("เหมือนแพนเค้ก", "เหมือนเราเหยียบกระป๋อง")
- ความเร็ว 13.3 ตัว/วิ ต่อเนื่อง ไม่มีช่วงเงียบ = ไม่มีที่ให้คนดูหลุด

## 4. ภาพ / ตัดต่อ
- **ฐานหลัก = พิธีกรหน้ากล้อง** (ห้องมืด ไฟแดงพื้นหลัง โคมไฟส้ม ไมค์ในเฟรม) 71% ของเวลา — ภาพที่ "ถูก" ที่สุด ทำให้คลิป 40 นาทีผลิตได้
- ภาพแทรกเข้าตรงคำที่พูดถึง: ภาพตึก/บุคคล/ข่าว/ภาพถ่ายเก่า วางเป็น **การ์ดขอบมนมีเงา vignette บนพื้นดำ** หรือเต็มจอ; แผนภาพโครงสร้าง (ภาพตัดอาคาร, แบบแปลน, ภาพวาดมือ) ตอนอธิบายเชิงเทคนิค
- cold open ใช้ฉากจำลอง/ละคร + ภาพเหตุการณ์ ตัดทุก 1-3 วิ
- เกรดสีอุ่นเก่า (ฟิล์มซีด, vignette) ให้ภาพทุกแหล่งเข้าชุดกัน
- ซับ/ข้อความบนจอน้อยมาก (มีแค่คำบรรยายในภาพข่าวที่ติดมา)
- เสียง: เพลงดนตรีกระแทกหลัง cold open, ที่เหลือเพลงคลอเบามาก พูดเด่น

## 6. วิธีสร้าง (สายพานคลิปยาว ร่าง — ยังไม่เคยทดลองจริง)
1. หัวข้อ: เรื่องที่มี "ห่วงโซ่เหตุ" ชัด + ตัวเลขชัด + เอกสารทางการ (อุบัติเหตุวิศวกรรม, ภัยพิบัติที่มีรายงานสอบสวน, ปริศนาที่วิทยาศาสตร์ไขแล้ว) — เช็กยอดวิวคลิปยาวไทย/ต่างประเทศ (ตัวกรอง 4-20 นาที `sp=EgIYAw%3D%3D`)
2. research.md แบบลำดับเวลา + แหล่งทุกข้อ (รายงานทางการ ≥1 + แหล่งรอง ≥1)
3. outline ตามโครงข้อ 2 (cold open → ปูฉาก → ห่วงโซ่นับข้อ → วันเกิดเหตุปิดลูป → มนุษย์ → สรุป) กำหนดจุดดึงทุก 60-90 วิ
4. script.md เป็นบท (chapter) ละ 1-2 นาที ผ่านขั้นเกลาภาษาพูด (style.md) — ใส่บทพูดแทนตัวละครเฉพาะที่แหล่งรองรับ
5. shotlist ต่อบท: ภาพแทรกทุก 5-10 วิ (ถ้าไม่มีพิธีกร) ผูกกับคำพูด (shot_times แบบเดิม)
6. ตัดต่อ HyperFrames 1920x1080 แยก composition ต่อบท แล้วรวม; เกรดสีชุดเดียว; cold open ตัดถี่ 1-3 วิ
7. ตรวจ (reviewer ต่อบท) → ปก 16:9 + ชื่อ/คำอธิบายมี chapter (yt-description-writer) → ตัด Shorts
