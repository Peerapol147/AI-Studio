# คู่มือสไตล์: ช่องความรู้ทั่วไป (Shorts / TikTok)

## ทิศทาง 2026-11-22: ตัดต่อ v3 (ผู้ใช้อนุมัติ "แก้ปรับปรุงได้เลย", ชนะกฎเก่าในไฟล์นี้เมื่อขัดกัน)
ที่มา: `docs/editing-research-2026-11-22.md` (branch `claude/content-strategy`) รายละเอียดและวิธีใช้: `docs/editing-v3.md`
เหตุผล: ทุกคลิปใช้แม่แบบ brainrot-v2 + เพลง/เสียง AI แบบเดิม ตรงกับตัวอย่างในนโยบาย "เนื้อหาไม่แท้/แม่แบบ" ของ YouTube (เสี่ยงหาเงินไม่ได้ทั้งช่อง)
และคลิปส่วนใหญ่แพ้ตั้งแต่ 3 วิแรก/ช่วงกลาง (ยังไม่มีหลักฐานว่าโดนบล็อกเป็นสแปม)
1. **Hook:** เฟรม 0 = คำถามบนจอ + ภาพที่ทำให้แปลกใจ; พูดหัวข้อให้จบภายใน 1.5 วิ; ห้ามเปิดด้วยโลโก้/ทักทาย/ปูพื้น;
   ยังเขียน hook 3 แบบ + เทสต์ปิดเสียงเหมือนเดิม (`tools/pacing.py` เช็กเวลาพูดหัวข้อจาก words.json)
2. **ลูป:** ประโยคสุดท้ายต้องต่อเข้าประโยคแรกได้ (อ่านประโยคสุดท้ายแล้วต่อด้วยประโยคแรก ต้องเป็นภาษาที่ลื่น) แต่ทั้งสองยังเป็นประโยคที่จบในตัว
   (กฎเดิม "ห้ามประโยคค้างเพื่อทำ loop" ยังใช้) ภาพเฟรมสุดท้ายต้องเข้ากับเฟรมแรก (แม่แบบ v3 ทำให้: ช็อต loop เล่นภาพ hook จบที่เฟรม 0)
3. **โครงจังหวะ:** hook → ปูเรื่อง → **เฉลยคำตอบที่ ~50-60% ของความยาว** → หักมุม/ข้อแถม 1 ข้อ → **"ข้อเท็จจริงน่าส่งต่อ" 1 ข้อ** (เช่น "ส่งให้เพื่อนที่ชอบ...")
   → คำถามชวนคอมเมนต์ ≤4 วิ (กฎเดิม); แนวตำนาน/ลี้ลับ: เล่าเรื่อง 70 / หักมุม 30 (`"genre": "legend"` ใน shots.json)
   ทุกช็อตใน shots.json มี `"beat"`: hook / setup / explain / reveal / twist / share / cta / loop
4. **จังหวะตัด:** ตัดเร็วเฉพาะช่วง hook และหักมุม (beat hook/twist); ช่วงอธิบาย (explain) ค้างภาพ 2-3 วิ ไม่ตัดถี่ตลอดคลิป
   (ค้างภาพ = ไม่ตัด แต่ภาพยังขยับช้าๆ ด้วย push-in ของแม่แบบ จึงไม่ขัดกฎ "ห้ามเฟรมนิ่งเกิน 0.5 วิ")
   ซับ 1-3 คำต่อจังหวะ ไฮไลต์คำสำคัญ (`*คำ*`)
   แทนกฎ "ช็อตเฉลี่ย ~1.4 วิ ทั้งคลิป" / "ช็อตเฉลี่ย ≤1.8 วิ" ด้านล่าง
5. **เลิกแม่แบบเดียว (สำคัญสุด):** ทุกตอนเลือกหน้าตา (โทนสี, ฟอนต์, สไตล์ซับ, โครงเปิด question/midstory/pov/number, ทรานซิชัน, อารมณ์เพลง, เสียงพากย์ตามแนวเรื่อง)
   จาก `templates/looks/looks.json` จดใน `projects/<id>/look.json` แล้ว `python3 tools/look.py check <project>` ต้องผ่าน
   (ห้ามสี/โครงเปิดเหมือนตอนก่อน, ห้ามหน้าตาเหมือน 1 ใน 3 ตอนล่าสุดทุกด้าน, **ห้ามเพลงพื้นหลังเดิมซ้ำติดกัน**) ตัดต่อด้วย `templates/brainrot-v3/`
6. **จังหวะลงคลิป (คำแนะนำ ไม่มีหลักฐานว่าลงเยอะแล้วโดนลงโทษ):** วันละ 1-2 คลิป เว้นระยะ ไม่ลง 5-6 คลิปวันเดียว
   เพื่อแยกผลแต่ละคลิปได้ชัด และเอาแรงไปทำคุณภาพต่อคลิป

## บทพูดแบบที่ผู้ใช้ต้องการ (ผู้ใช้สอน 2026-11-19 ตอน brainrot, ชนะกฎความยาวด้านล่างเมื่อขัดกัน)
ผู้ใช้: "บทแปลก พูดไม่เข้าใจ คำใช้บริบทสะเปะสะปะ" แล้วเขียนบทเองให้ดู: "ประมาณนี้ เกลาเพิ่มถ้าข้อมูลไม่ถูก แต่ธรรมชาติคือแบบนี้"
- **ความเข้าใจมาก่อนความยาว (ผู้ใช้ 2026-11-19: "40 วิยังได้ เน้นคุณภาพ"):** ยาวได้ถึง 40 วิ ถ้าเกิน ให้ตัดทั้งประเด็น ไม่ใช่ตัดคำเชื่อม/ประธานจนประโยคขาด; 1 ตอน = 1 ความเชื่อ + 1 หลักฐาน + 1 ทริก
- **ภาษาพูดเต็มประโยค มีประธานและคำเชื่อม:** "มันฮิตซะจน...", "แต่ยังไม่มีหลักฐานว่า...นะ", "งานวิจัยแค่เจอว่า...", "หรืออาจเป็นเพราะ...ก็ได้", "ทริกง่ายๆนะ..."
- **ศัพท์ใหม่/ทับศัพท์ ต้องอธิบายทันทีในประโยคถัดจาก hook** ("Brainrot แปลว่าสมองเน่า...") และยกตัวอย่างที่คนดูเห็นภาพ ("ไถคลิปแนว short หรือ tiktok ทั้งคืน")
- ใช้คำที่คนไทยพูดจริง: "ไถ" ไม่ใช่ "เลื่อน", "เมนต์บอกหน่อย", "จริงหรอ?"
- **ห้ามมุกภาษาศาสตร์/คำแปลที่ต้องอธิบายยาว** (เช่น "supposed" = "คนคิดว่า") และ**ห้ามประโยคค้างเพื่อทำ loop** ("...ก่อนสงสัยอีกรอบว่า") ให้วนด้วยภาพแทน
- ปิดด้วยคำถามคอมเมนต์ + ประโยคใส่ใจสั้นๆ ได้ ("อย่าลืมพักผ่อน")
- ผู้กำกับเกลาเฉพาะจุดที่ข้อเท็จจริงเกิน research (เช่น "แย่มากกว่า"→"แย่กว่า") ไม่เปลี่ยนสำนวนธรรมชาติของบท
  คำที่เกลาต้องเป็นคำที่คนไทยพูดจริง ห้ามคำแปลแข็งๆ (ผู้ใช้: "หลับไม่ค่อยดี คนไทยไม่ใช้" → ใช้ "หลับยาก" / "หลับไม่สนิท"); ถ้าหาคำธรรมชาติที่ตรงหลักฐานไม่ได้ ให้ถามผู้ใช้
- ตัวอย่าง v2 (แย่) → v3 (ดี): "Oxford ยกให้เป็นคำแห่งปี 2024" → "มันฮิตซะจน Oxford เลือกเป็นคำแห่งปี 2024"; "แต่แค่สัมพันธ์กัน อาจเพราะเครียดเลยเลื่อนหนัก" → "หรืออาจเป็นเพราะเครียดอยู่แล้ว เลยทำให้ไถหน้าจอหนักกว่าเดิมก็ได้"
- (ประวัติ: ตั้งแต่ 2026-11-22 ใช้ v3 + look.json ดูหัวไฟล์) **ตัดต่อที่ผู้ใช้ชอบ = ดราฟต์ brainrot v2** (26 วิ, ช็อตเฉลี่ย 1.38 วิ, เสียงพากย์พาวนกลับ hook) ไม่ใช่ v3 (35 วิ, 1.53 วิ) → ให้สั้นด้วยการลดประเด็น ไม่ใช่ตัดคำ; รายละเอียด `projects/2026-11-19-knowledge-brainrot/feedback.md`

## ทิศทางจากผลจริง (อัปเดต 2026-11-18, ดู `results.md`)
- **หัวข้อ:** "ทำไม...?" เรื่องร่างกาย/ชีวิตประจำวันที่คนเคยสงสัยเอง เป็นหลัก (คลิปวิวสูงสุดเป็นแนวนี้)
  สัตว์แปลกยังได้ผลใกล้เคียง (วอมแบต ~1K) สลับได้ ยังไม่ตัดทิ้ง
- **ชื่อคลิป = คำถาม "ทำไม...?"** สั้น ตรง ใช้คำที่คนพิมพ์ค้นจริง
- **ความยาว 15-20 วิ** (คนดูเฉลี่ย ~11-16 วิ) บท 220-300 ตัวอักษร ตัดช่วงอธิบายเหลือกลไกเดียว
- **Hook = ตัวแปรที่สำคัญที่สุด** (Stayed to watch 52-62%, เป้า ≥ 70%):
  เฟรมแรกต้องเป็นภาพที่ตอบคำถามไม่ได้ทันที + ข้อความคำถามตัวใหญ่บนจอตั้งแต่ 0.0 วิ
  ประโยคแรกเข้าเรื่องทันที ไม่ทักทาย ไม่ใช้ "เพื่อนๆ รู้ไหมว่า" (ใช้กันเกลื่อน)
  ภายใน 1.5 วิต้องมีภาพเปลี่ยน/การเคลื่อนไหวครั้งแรก
  **เฟรมแรกของคลิปสำคัญกว่าปก** (ใน feed คนเห็นเฟรมแรก) ทำเฟรม 0.0 วิให้ดูเหมือนปก: คำถามตัวใหญ่ + ภาพเด่น

ถอดจากคลิปตัวอย่างที่ผู้ใช้ส่งมา 2 คลิป (เรียนแค่รูปแบบ ห้ามลอกเนื้อหา ภาพ หรือบทของเขา)
ทุกตำแหน่งในทีมอ่านไฟล์นี้ก่อนทำคลิปของช่องนี้

## ภาพรวมที่ทั้งสองคลิปเหมือนกัน
- **ยาว 23-26 วินาที** (เป้า 20-30 วิ) แนวตั้ง 9:16 ไม่มีบทนำ ไม่มีโลโก้เปิด ไม่มีขอกดติดตามท้ายคลิป
- **เสียงพากย์เริ่มที่ 0.06 วิ** และพูดต่อเนื่องจนจบ ไม่มีช่วงเงียบเกิน 0.4 วิ
- **พูดเร็ว ~15 ตัวอักษรไทย/วินาที** (บท 350-400 ตัวอักษร ≈ 25 วิ) น้ำเสียงเล่าเรื่องแบบคุยกับเพื่อน มั่นใจ ไม่ตะโกน
- **บทเป็นก้อนเดียวไหลต่อกัน** ตามโครง: คำถาม/สถานการณ์ → สิ่งที่คนคิด → "แต่ความจริงคือ" → กลไก/เหตุผล → ปิดด้วยผลลัพธ์ชัดๆ
  ใช้ภาษาพูด ("เพื่อนๆ รู้ไหมว่า", "นั่นเอง", "ตุย") ไม่ใช้ภาษาเขียนหรือศัพท์วิชาการ
- **ซับเด้งทีละ 1-3 คำ** (≈ 0.5-1 วิ ต่อก้อน) ตรงกับเสียงพากย์ทีละคำ
  สีขาว ขอบดำหนา ไม่มีกล่องพื้นหลัง วางกึ่งกลางแนวนอน ที่ **~58-60% ของความสูงจอ** (ใต้กลางจอเล็กน้อย พ้นปุ่มด้านล่าง)
  ฟอนต์: Kanit 600-700 หรือ Prompt 700 จาก `assets/fonts/`, ขนาด ≈ 6-7% ของความกว้างจอ
- **เพลงประกอบเบาๆ ต่อเนื่องตลอด** ใต้เสียงพากย์ (ducking) ไม่มีช่วงเงียบ
