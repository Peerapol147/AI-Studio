# คู่มือสไตล์: ช่องความรู้ทั่วไป (Shorts / TikTok)

ถอดจากคลิปตัวอย่างที่ผู้ใช้ส่งมา 2 คลิป (เรียนแค่รูปแบบ ห้ามลอกเนื้อหา ภาพ หรือบทของเขา)
ทุกตำแหน่งในทีมอ่านไฟล์นี้ก่อนทำคลิปของช่องนี้

## ภาพรวมที่ทั้งสองคลิปเหมือนกัน
- **ยาว 23-26 วินาที** (เป้า 20-30 วิ) แนวตั้ง 9:16 ไม่มีบทนำ ไม่มีโลโก้เปิด ไม่มีขอกดติดตามท้ายคลิป
- **เสียงพากย์เริ่มที่ 0.06 วิ** และพูดต่อเนื่องจนจบ ไม่มีช่วงเงียบเกิน 0.4 วิ
- **พูดเร็ว ~15 ตัวอักษรไทย/วินาที** (บท 350-400 ตัวอักษร ≈ 25 วิ) น้ำเสียงเล่าเรื่องแบบคุยกับเพื่อน มั่นใจ ไม่ตะโกน
- **บทเป็นก้อนเดียวไหลต่อกัน** ตามโครง: คำถาม/สถานการณ์ → สิ่งที่คนคิด → "แต่ความจริงคือ" → กลไก/เหตุผล → ปิดด้วยผลลัพธ์ชัดๆ
  ใช้ภาษาพูด ("เพื่อนๆ รู้ไหมว่า", "นั่นเอง", "ตุย") ไม่ใช้ภาษาเขียนหรือศัพท์วิชาการ
- **ซับเด้งทีละ 1-3 คำ** (≈ 0.5-1 วิ ต่อก้อน) ตรงกับเสียงพากย์ทีละคำ
  สีขาว ขอบดำหนา ไม่มีกล่องพื้นหลัง วางกึ่งกลางแนวนอน ที่ **~58-60% ของความสูงจอ** (ใต้กลางจอเล็กน้อย พ้นปุ่มด้านล่าง)
  ฟอนต์: Kanit 600-700 หรือ Prompt 700 จาก `assets/fonts/`, ขนาด ≈ 6-7% ของความกว้างจอ
- **เพลงประกอบเบาๆ ต่อเนื่องตลอด** ใต้เสียงพากย์ (ducking) ไม่มีช่วงเงียบ

## รูปแบบ A: "รู้ไหมว่า" + footage จริง (ทำได้เต็มรูปแบบ)
ตัวอย่าง: เรื่องสัตว์/ธรรมชาติ/ร่างกาย/ข้อเท็จจริงแปลกๆ
- hook ประโยคแรก "เพื่อนๆ รู้ไหมว่า + ข้อเท็จจริงที่ฟังดูเหลือเชื่อ" (ภายใน 2 วิ)
- **ตัดภาพเร็ว: ~18 ช็อตใน 26 วิ (เฉลี่ย 1.4 วิ/ช็อต, ช่วง 0.6-2.7 วิ)** ทุกช็อตตรงกับคำที่กำลังพูด
  (พูด "ลิง" → ภาพลิง, พูด "อาหารมหาศาล" → ภาพกินอาหาร)
- footage จริงจาก Pixabay / Wikimedia / NASA เต็มจอ ครอปให้เป็น 9:16 ไม่มีขอบดำ
- ใส่ zoom/pan ช้าๆ (Ken Burns 3-8%) ให้ภาพนิ่งดูมีชีวิต
- ทางเลือก: ไอคอน "หน้าผู้เล่า" ในวงกลมมุมซ้ายล่าง 2-3 วิแรก (ใช้ภาพ/มาสคอตของช่องเอง ถ้ามี)
- จบด้วยประโยคหักมุม/สรุปตลก แล้ว**ปิดด้วยคำถามชวนคอมเมนต์ 1 ประโยค** ("แล้วเพื่อนๆ คิดว่า...?") ไม่เกิน 4 วิ ตัดจบทันที

## รูปแบบ B: แอนิเมชันอธิบายกลไก (3D ภาพตัดขวาง)
ตัวอย่าง: สิ่งนี้ทำงานยังไง (กับดัก เครื่องยนต์ อวัยวะ สิ่งประดิษฐ์)
- **กล้องเคลื่อนต่อเนื่อง แทบไม่มีการตัด** (2-4 ช็อตทั้งคลิป) ซูมเข้าไปในจุดสำคัญตามบท
- ภาพตัดขวาง (cutaway) ให้เห็นข้างใน, ชิ้นส่วนสำคัญเรืองแสง/ใส, จบด้วยการ "ทำงาน" (เช่น ระเบิด แสงวาบ) แล้วถอยกล้องออก
- เปิดและปิดด้วยฉากเดียวกัน (เป็นลูปดูซ้ำได้)
- ผู้ใช้เลือก: ทำเป็น **2D motion ภาพตัดขวาง** (ไม่ทำ 3D)
  ใน HyperFrames (ดู `.claude/skills/hyperframes/references/types/explainer.md`)

## เลือกรูปแบบ
- หัวข้อ "อะไร/ทำไม/จริงไหม" ที่มีภาพจริงหาได้ → A
- หัวข้อ "ทำงานยังไง" ที่ต้องเห็นข้างใน หรือหาภาพจริงไม่ได้ → B
- ไม่แน่ใจ → A (เร็วกว่าและใกล้ตัวอย่างกว่า)

## เช็กลิสต์ก่อนส่ง (ผู้ตรวจใช้)
- [ ] 20-30 วิ, เสียงพากย์เริ่ม < 0.3 วิ, ไม่มีช่วงเงียบ > 0.4 วิ
- [ ] บท 300-450 ตัวอักษร มี "แต่ความจริงคือ" หรือจุดหักมุม และจบด้วยคำถามชวนคอมเมนต์
- [ ] ซับ 1-3 คำต่อก้อน ขาวขอบดำ ที่ ~60% ความสูง ตรงเสียงทีละคำ
- [ ] รูปแบบ A: ช็อตเฉลี่ย ≤ 1.8 วิ และภาพตรงกับคำที่พูด

## Motion (v2 หลังผู้ใช้บอกว่าแอนิเมชันแปลก)
- กราฟิก 2D ใช้หลักของ skill `motion-broll`: **รูปร่างเดียวที่ morph ต่อเนื่อง ไม่ตัด** (ขนาด มุม สี เปลี่ยนแบบ spring), ทุกการเปลี่ยนลงตรงคำพูด, มี motion blur, ห้ามของโผล่/หายแบบกระตุก
- ระบบเสียง: ใช้ skill `sound-effects` (เสียง CC0 ของจริง, มิกซ์ -16 LUFS, peak < -4 dBFS, 1 เสียงต่อ 1 cue)
