# ระบบภาพปก ช่องความรู้ (Shorts) v1 — ทุกตอนใช้แบบเดียวกัน
ผู้ใช้ขอ: ปกธีมเดียวกัน คุมโทนให้เรียงสวยในหน้าช่อง YouTube และดึงให้คนกดดู

## ส่วนที่ "ห้ามเปลี่ยน" (ทำให้กริดดูเป็นซีรีส์)
- กรอบเหลือง `#FFD60A` หนา 14px มุมโค้ง ล้อมทั้งปก
- ป้ายเม็ดยาสีเหลืองบนสุด: ไทย "รู้ไหม?" / อังกฤษ "DID YOU KNOW?" ตำแหน่งเดิมทุกตอน
- พาดหัว Kanit 900 สีขาว ขอบกรมท่า `#0B1630` อยู่ช่วงบน 15-40% ของปก 2 บรรทัด (สูงสุด 3)
- คำสำคัญ 1 คำ อยู่ใน **กล่องเหลือง ตัวกรมท่า เอียง -2.5°** (เขียน `[คำ]` ใน cover.json)
- ภาพจริงเต็มจอ ปรับสีเหมือนกันทุกตอน (saturate/contrast) ไล่เฉดกรมท่าด้านบนและล่าง
- (ไม่บังคับ) สติกเกอร์วงกลมขอบเหลือง ขวาล่าง แสดงสิ่งที่สอง (เช่น ตัวการ/ของในเรื่อง)

## ส่วนที่เปลี่ยนต่อตอน (เพื่อให้คนกด)
- ภาพหลัก: **หน้าคน/สัตว์ ใกล้ๆ เห็นตา อารมณ์ชัด** อยู่ครึ่งล่าง (ใต้พาดหัว) ไม่ใช่ภาพวิว
- พาดหัว ≤ 5 คำ เป็น "ความขัดแย้ง/สิ่งที่ฟังดูผิด" ไม่ซ้ำกับชื่อคลิป ห้ามสปอยคำตอบ
  เช่น "ไม่หิวน้ำ / แต่[ขาดน้ำ]" "ขี้ออกมา / เป็น[ลูกเต๋า]!"
- ข้อความทุกคำต้องจริงตาม research.md (ห้ามเกินจริง)
- อ่านออกที่ขนาดย่อ 120px: เช็กด้วยการย่อภาพแล้วดู

## วิธีทำ
1. ผู้กำกับเขียน `<project>/cover.json` ตอนขั้น 3 (ข้อความ) ใส่ภาพหลังจาก footage มาแล้ว
2. `node tools/cover.js <project> th` และ `en` → `<project>/cover-<lang>.jpg` + `renders/<slug>-<lang>-thumb.jpg`
3. ส่งไฟล์ปกแยกให้ผู้ใช้ตั้งเป็นปกเอง (YouTube Shorts: ตั้งปกจากแอปมือถือ, TikTok: เลือกปกจากรูป)
4. reviewer: ย่อเป็น 120px กว้าง ต้องอ่านพาดหัวออก, วรรณยุกต์ไม่ล้นกล่อง, ไม่มีโลโก้/ลายน้ำ
